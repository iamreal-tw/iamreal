# 證明紀錄頁

「證明紀錄」那一頁，導覽列上也叫「證明紀錄」；首頁的「看其他人的島民證明」「看一張島民證明的樣子」連到這裡（`home.md`「第一屏」「不必公開你是誰」）。原則在 `docs/design/principles.md`。

四塊，由上到下：查詢、數字、下載、清單。

例子裡的 `@alice`、`@bob`、`@carol`、`@carol.tw`、`Threads`、`7K2Q9FM4XD`、`3M8T1RZ6WA`、`9Q4C2XN7B4`、日期、`1,284`、`1,031` 是會換掉的值，其餘是固定的文字。「查」「更多」「下載全部的證明紀錄」「如何驗證證明紀錄」是按鈕或連結。

```
證明紀錄

查一個 Threads 帳號
[ @              ]　[ 查 ]

現在有 1,284 張島民證明，其中 1,031 張在過去三個月內過卡。
每一列是一張自然人憑證的一次過卡：新宣告、更換、收回或再次過卡。每張自然人憑證對應到唯一的島民編號。帳號主人承不承認，要點進那一張看。

下載全部的證明紀錄　　如何驗證證明紀錄

2026-11-18　島民編號 7K2Q9FM4XD 開頭　新宣告：Threads 的 @alice
2026-11-18　島民編號 3M8T1RZ6WA 開頭　再次過卡：Threads 的 @bob
2026-11-17　島民編號 9Q4C2XN7B4 開頭　更換：Threads 的 @carol 改成 @carol.tw
……
更多
```

## 查詢

查詢框在數字前面。按「查」之後到那個帳號的查詢頁（`account-page.md`）。輸入去掉前後的空白和開頭的 `@`，大寫轉成小寫。

- 去掉之後是空的：照常顯示證明紀錄頁，不多任何一行
- 不合 Threads 帳號名稱的格式：照常顯示證明紀錄頁，查詢框裡保留訪客打的字，查詢框下面多一行：

```
Threads 的帳號名稱只有英文字母、數字、句點和底線。
```

## 數字

和首頁的兩個數字是同一組，算法見 `home.md`「一起能改變什麼」。

## 清單

- 一列是一筆有效的紀錄在 Threads 上做了什麼，照證明紀錄裡的順序，新的在上。再次過卡也列；收回也列。無效的紀錄不列。一張卡片同一天最多 3 筆有效的紀錄，每一筆都列
- 每一列只有文字：日期、島民編號的開頭、這一筆是哪一種和帳號。不放大頭貼，不嵌入個人檔案。整列連到那一張島民證明
- 「每一列是一張自然人憑證的一次過卡……」那一句放在張數那一行下面
- 日期是紀錄的日期，只到天，不顯示時間
- 一次五十筆，其餘按「更多」。「更多」是連結，接著上一頁的最後一筆往下列：上一頁打開之後才寫進來的紀錄不會讓下一頁重複或漏掉
- 不做依帳號名稱的瀏覽或排序

哪一種、帳號怎麼寫，和島民證明頁的證明紀錄用同一套詞（`proof-page.md` 第 3 段），多寫出平台，再次過卡也寫出帳號：

| 這一筆紀錄 | 畫面寫 |
|---|---|
| 新宣告 | 新宣告：Threads 的 @bob |
| 再次過卡 | 再次過卡：Threads 的 @bob |
| 更換 | 更換：Threads 的 @bob 改成 @alice |
| 收回 | 收回：Threads 的 @alice |
| 收回之後宣告回同一個帳號 | 再次宣告：Threads 的 @alice |
| 收回之後宣告別的帳號 | 更換：Threads 的 @alice 改成 @carol.tw |

證明紀錄裡還沒有任何一筆紀錄時，清單的位置只寫這一句；「每一列是……」那一句和「更多」不顯示：

```
證明紀錄裡還沒有島民證明。
```

## 下載

兩個連結在張數那一行和它下面的說明之後、清單之前，自己一行，不壓在五十筆的下面。證明紀錄裡還沒有任何一筆紀錄時，也一樣在張數那一行下面。

「下載全部的證明紀錄」連到 `cmd/iamreal-verify/README.md` 講下載的那一段（證明紀錄放在 `data.iamreal.tw`，ADR-0027）；「如何驗證證明紀錄」連到 `verify.md` 那一頁。

## 連結被貼出去時的預覽

```
標題：證明紀錄
網站：島民證明 iamreal.tw
```

- 不寫摘要；圖是每一頁同一張（`proof-page.md`「預覽圖」）
- 分頁的標題是預覽的標題後面加「｜島民證明」：`證明紀錄｜島民證明`
