# 島民證明的頁面

`iamreal.tw/p/7K2Q9FM4XD`，一張卡片一頁（ADR-0020）。這一頁是訪客看的：從一個帳號的個人檔案點進來，想知道上面的宣告算不算數的人。原則在 `docs/design/principles.md` 的「島民證明的頁面」。

- 不用打勾、綠色、「有效」「通過」：頁面給事實和日期，判斷留給訪客
- 一律寫「自然人憑證」，不簡稱「憑證」
- 稱呼用「你」
- 第一次上線只有 Threads，一張卡片一個帳號
- 字越少越好。訪客在這一頁只看三件事：帳號是誰、帳號主人的個人檔案上有沒有這張證明的連結、上次過卡是哪一天。其他的說明放在「如何檢查 Threads 帳號的島民證明」（`check.md`，`/check`），頁首的選單和頁尾都連到那一頁；頁面裡不另外放一段。頁面不顯示「驗證通過」這類的字，不顯示完整的島民編號，不直接連到「如何驗證證明紀錄」

例子裡的 `@alice`、`@bob`、`@carol.tw`、`Threads`、`7K2Q9FM4XD`、`7K2Q9FM4XD3A`、日期、天數、張數、順序號碼（`128`）是會換掉的值，其餘是固定的文字。「個人檔案」「過卡更新這張證明」「把它掛到個人檔案上」是連結，「我也要換島民證明」是按鈕。

下面第 1 到 4 段的順序就是頁面由上到下的順序，手機上照這個順序上下排；第 5 段以後是別的情況和頁面以外的文字。

桌機上兩欄：左欄是第 1、2 段，右欄是第 3 段，從標題的高度開始；第 4 段在兩欄下面。第 3 段的紀錄會越來越長，放在右欄往下長，不會把個人檔案推下去。

## 1. 標題和帳號

```
第 128 張島民證明

一張台灣國民的自然人憑證
宣告了 Threads 的

@alice
```

第一行在標題上方，是一行次要色的小字。數字是這張自然人憑證的順序號碼：它第一次留下有效的紀錄時，是證明紀錄裡的第幾張卡片（`spec/record-rules.md`「The ordinal」）。數字照 `home.md` 第 2 段的寫法，超過三位數時每三位加一個逗號（`第 1,284 張島民證明`）。帳號名稱旁邊不放號碼。

`@alice` 單獨一行，是第一屏最大的字。

這一段不放講範圍的句子（「這張證明只涵蓋 Threads 上的 @alice……」）：平台寫在標題裡；名稱要一字不差、帳號改了名稱的情況寫在 `check.md` 第 3 步和第 4 段；其他平台上同名的帳號寫在 `check.md` 第 3 段。

## 2. 個人檔案上的連結

```
個人檔案上有這個連結，才代表 @alice 承認本證明。

  iamreal.tw/p/7K2Q9FM4XD

（Threads 的個人檔案嵌入）
```

第一行是小標，斷行斷在逗號後面。「個人檔案」是連到 `https://www.threads.com/@alice` 的連結：頁面自己的文字，不靠嵌入，嵌入框顯示不出來時，訪客從這裡到 Threads 上看。

連結的字串不帶 `https://`，和 Threads 的嵌入顯示連結的寫法相同，緊貼在嵌入框上方。

嵌入框下面不放句子。頁面讀不到嵌入框裡的內容，後台不讀 Threads（ADR-0003），所以頁面不知道嵌入框有沒有顯示出來、個人檔案上有沒有這個連結，只能放任何情況都成立的話；小標已經說了有這個連結才代表承認，連到 Threads 的路也在小標上。

## 3. 上次過卡和證明紀錄

```
上次過卡：12 天前（2026-11-06）

這張自然人憑證的證明紀錄
2026-11-06　再次過卡
2026-08-01　更換：@bob 改成 @alice
2026-05-10　再次過卡
2026-03-02　新宣告：@bob

建議持卡人每三個月過卡一次
這是你的證明？過卡更新這張證明・把它掛到個人檔案上
```

第一行和標題一樣顯眼，括號裡的日期小一號、淡色。天數一律用天，不換成月或年；不論幾天樣式相同，不加警告。日期是證明紀錄裡的上次過卡日；天數照台灣的日期算。上次過卡日就是今天時，第一行寫：

```
上次過卡：今天（2026-11-18）
```

過卡日那一天檢查了什麼、之後為什麼不知道，寫在 `check.md` 第 4 步，這裡不寫。

「這張自然人憑證的證明紀錄」是小標。下面一筆紀錄一列，全部列出、不折起來，新的在上；不另外做「第一次過卡」「過卡幾次」這類的摘要，最下面一列就是第一次過卡，換過帳號的那幾列寫著前後的帳號。只列有效的紀錄。同一天有好幾筆時照證明紀錄裡的順序排，新的在上；不顯示時間。

最後兩行是小字，在紀錄下面。「建議持卡人每三個月過卡一次」是固定的頻率建議，讓訪客有一把尺自己比（原則 4）。「過卡更新這張證明」連到過卡的第 1 步（`/proof`），「把它掛到個人檔案上」連到這張證明的掛上去（`/hang/7K2Q9FM4XD`，`hang.md` 第 2 部分），兩個都是連結，不是按鈕；這一行給持卡人和帳號主人，放在最後，不擋在訪客要看的東西前面。

每一筆紀錄的寫法：

| 這一筆紀錄 | 畫面寫 |
|---|---|
| 新宣告 | 2026-03-02　新宣告：@bob |
| 再次過卡 | 2026-05-10　再次過卡 |
| 更換 | 2026-08-01　更換：@bob 改成 @alice |
| 更正 | 2026-08-01　更正：@bob 改成 @alice |
| 收回 | 2026-11-15　收回：@alice |
| 收回之後宣告回同一個帳號 | 2026-11-17　再次宣告：@alice |
| 收回之後宣告別的帳號 | 2026-11-17　更換：@alice 改成 @carol.tw |

## 4. 換一張自己的

```
一張自然人憑證只能換一張島民證明，上面只能宣告一個 Threads 帳號。

[ 我也要換島民證明 ]
```

「我也要換島民證明」是按鈕，連到過卡的第 1 步（`/proof`）；過卡要準備什麼，第 1 步會講。全頁只放一次。

## 5. 全部收回之後

這張自然人憑證收回了所有帳號時：

```
第 128 張島民證明

這張自然人憑證現在沒有把名額給任何帳號

上次過卡：3 天前（2026-11-15）
那一天收回了 Threads 的 @alice。
```

標題上方那一行和第 1 段相同：收回不改變順序號碼。沒有第 1 段的帳號，沒有第 2 段。「上次過卡」那一行和標題一樣顯眼，下面是「那一天收回了 Threads 的 @alice。」那一行小字，再下面是第 3 段的證明紀錄，照常全部列出；第 3 段最後兩行小字不顯示。收回的帳號只出現在小字那一行和紀錄裡，不放大。桌機上標題在左欄，「上次過卡」和紀錄在右欄。第 4 段照常。

## 6. 短編號對到兩張以上

網址的短編號對到兩張以上的自然人憑證時，最上面：

```
這個網址對到 2 張自然人憑證
它們的島民編號開頭 10 個字元碰巧相同，彼此沒有關聯。
```

下面每一張各放一份完整的內容（第 1 到 3 段，或第 5 段），照島民編號的字元順序排，每一張的排法和只有一張時相同。每一份上方一行寫出比較長的島民編號開頭，讓人分得出來：

```
島民編號 7K2Q9FM4XD3A 開頭
```

寫幾個字元：從 10 個字元起，加到這幾張互不相同為止。

第 4 段全頁只放一次，在最後一張的後面。

## 7. 連結被貼出去時的預覽

這一頁的連結貼到社群平台或通訊軟體時，預覽顯示：

```
標題：一張自然人憑證宣告了 Threads 的 @alice
網站：島民證明 iamreal.tw
```

- 分頁的標題（`<title>`）是預覽的標題後面加「｜島民證明」：`一張自然人憑證宣告了 Threads 的 @alice｜島民證明`；下面三種情況也一樣
- 不寫摘要
- 不放日期：平台會把預覽存很久
- 不放順序號碼：標題有帳號名稱，帶了號碼就等於把號碼放在帳號名稱旁邊
- 圖見下面「預覽圖」，上面沒有帳號名稱（原則 4：島民證明的樣子不能像平台的官方認證）
- 標題比頁面上的短，是為了帳號名稱不被截掉
- 預覽的文字要在送出頁面時就寫好
- 全部收回之後（第 5 段），標題是「這張自然人憑證現在沒有把名額給任何帳號」；短編號對到兩張以上時（第 6 段），標題是「這個網址對到 2 張自然人憑證」；對不到任何卡片時（第 8 段），標題是「找不到這張島民證明」

### 預覽圖

網站的每一頁都用同一張圖，這一頁也是；有預覽的頁面才有圖。圖和首頁同一層（`design/DESIGN.md`「兩層」），樣子照 `design/screens/og-image.png`：左邊是記號和下面的字，右邊是一片點，其中一個紅點是「你」。圖上沒有帳號名稱、日期、島民編號：平台會把圖存很久，而且每一頁都是同一張。

圖上的字，由上到下：

```
島民證明
即便是小國小民
也能一起讓網路的聲量更真實
iamreal.tw
```

替代文字：

```
島民證明：即便是小國小民，也能一起讓網路的聲量更真實。iamreal.tw
```

## 8. 短編號對不到任何卡片時

```
找不到這張島民證明

iamreal.tw/p/7K2Q9FM4XD 沒有對到任何一張自然人憑證。請確認網址有沒有抄錯。

如果你是從某個帳號的個人檔案點進來的，請留意這張島民證明並不存在。

查一個 Threads 帳號
```

- 網址那一行顯示的是訪客打開的網址
- 「查一個 Threads 帳號」是連結，連到證明紀錄頁（`proof-log-page.md`），停在查詢的那一欄
