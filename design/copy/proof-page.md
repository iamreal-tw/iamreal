# 島民證明的頁面

`iamreal.tw/p/7K2Q9FM4XD`，一張卡片一頁（ADR-0020）。這一頁是訪客看的：從一個帳號的個人檔案點進來，想知道上面的宣告算不算數的人。原則在 `docs/design/principles.md` 的「島民證明的頁面」。

- 不用打勾、綠色、「有效」「通過」：頁面給事實和日期，判斷留給訪客
- 一律寫「自然人憑證」，不簡稱「憑證」
- 稱呼用「你」
- 第一次上線只有 Threads，一張卡片一個帳號

例子裡的 `@alice`、`@bob`、`@carol.tw`、`Threads`、`7K2Q9FM4XD`、`7K2Q9FM4XD3A`、日期、天數、過卡和更換的次數、張數、順序號碼（`128`）是會換掉的值，其餘是固定的文字。「如何檢查 Threads 帳號的島民證明」「Threads 的 @alice」「我要更新這張證明」「把它掛到個人檔案上」是連結，「我也要換島民證明」是按鈕。

下面第 1 到 5a 段的順序就是頁面由上到下的順序；第 6 段以後是別的情況和頁面以外的文字。

桌機上兩段並排：第一屏左欄是第 1、2 段，右欄是第 3 段；下面左欄是第 4 段，右欄是第 5 段；第 5a 段在最下面。手機上照第 1 到 5a 段的順序上下排。

## 1. 標題和帳號

第一屏，左欄。

```
第 128 張島民證明

一張台灣國民的自然人憑證，
把它在 Threads 唯一的名額給了

@alice

這張證明只涵蓋 Threads 上的 @alice。名稱不同的帳號、Instagram 或其他平台上同名的帳號，都和這張證明無關。
```

第一行在標題上方，是一行次要色的小字。數字是這張自然人憑證的順序號碼：它第一次留下有效的紀錄時，是證明紀錄裡的第幾張卡片（`spec/record-rules.md`「The ordinal」）。數字照 `home.md` 第 2 段的寫法，超過三位數時每三位加一個逗號（`第 1,284 張島民證明`）。帳號名稱旁邊不放號碼。

`@alice` 單獨一行，是第一屏最大的字。最後一句是小字，緊接在帳號下面。

## 2. 上次過卡

第一屏，左欄，第 1 段下面。

```
上次過卡：12 天前（2026-11-06）
過卡日當天，這張自然人憑證在效期內，不在廢止清冊上。無法判斷卡片是否依然有效，要等下一次過卡才知道。因此越久沒過卡，這張證明的說服力越低，建議持卡人每三個月過卡一次。
我要更新這張證明
```

第一行和標題一樣顯眼，括號裡的日期小一號、淡色；下面一段是小字。天數一律用天，不換成月或年；不論幾天樣式相同，不加警告。日期是證明紀錄裡的上次過卡日；天數照台灣的日期算。

「我要更新這張證明」是那一段小字下面自己一行的連結，連到過卡的第 1 步（`/proof`）；不是按鈕。全部收回的頁面（第 6 段）沒有那一段小字，也沒有它。

上次過卡日就是今天時，第一行寫：

```
上次過卡：今天（2026-11-18）
```

## 3. 帳號主人承不承認

第一屏，右欄。

```
帳號主人承認這張證明嗎？
@alice 的個人檔案上有這個連結，才代表帳號主人承認這張證明：

  iamreal.tw/p/7K2Q9FM4XD

（Threads 的個人檔案嵌入）

@alice 的個人檔案上沒有 7K2Q9FM4XD，代表帳號主人可能沒有承認這張證明。
個人檔案顯示不出來時，請到 Threads 上看：Threads 的 @alice

這是你的帳號？把它掛到個人檔案上
```

第一行是小標。連結的字串不帶 `https://`，和 Threads 的嵌入顯示連結的寫法相同，緊貼在嵌入框上方。

嵌入框下面兩句固定顯示，不依嵌入框的狀態切換：頁面讀不到嵌入框裡的內容，後台不讀 Threads（ADR-0003）。

「Threads 的 @alice」是連到 `https://www.threads.com/@alice` 的連結，是頁面自己的文字，不靠嵌入。

最後一行是小字，給帳號主人看，放在比對用的字之後，不夾在要比對的連結和嵌入框中間。「把它掛到個人檔案上」連到這張證明的掛上去（`/hang/7K2Q9FM4XD`，`hang.md` 第 2 部分）。

## 4. 這張自然人憑證的證明紀錄

第一屏下面，左欄。

```
這張自然人憑證的證明紀錄
順序　第 128 張島民證明
第一次過卡　2026-03-02
過卡次數　4 次
更換帳號　在 Threads 更換過 1 次帳號（一張自然人憑證最多 5 次）

全部紀錄
2026-11-06　再次過卡
2026-08-01　更換：@bob 改成 @alice
2026-05-10　再次過卡
2026-03-02　新宣告：@bob
```

第一行是小標。下面四行直接顯示，排成兩欄：左欄是標籤（「順序」「第一次過卡」「過卡次數」「更換帳號」），右欄是值。「順序」的數字和第 1 段標題上方那一行相同。「全部紀錄」預設折起來，展開後一筆紀錄一列，新的在上。以前宣告過的帳號只出現在「全部紀錄」裡。

「全部紀錄」只列有效的紀錄；「第一次過卡」「過卡幾次」「更換過幾次」也只算有效的紀錄。同一天有好幾筆時照證明紀錄裡的順序排，新的在上；不顯示時間。

更換 0 次時照樣寫，樣式相同：

```
更換帳號　在 Threads 更換過 0 次帳號（一張自然人憑證最多 5 次）
```

「全部紀錄」每一列的寫法：

| 這一筆紀錄 | 畫面寫 |
|---|---|
| 新宣告 | 2026-03-02　新宣告：@bob |
| 再次過卡 | 2026-05-10　再次過卡 |
| 更換 | 2026-08-01　更換：@bob 改成 @alice |
| 收回 | 2026-11-15　收回：@alice |
| 收回之後宣告回同一個帳號 | 2026-11-17　再次宣告：@alice |
| 收回之後宣告別的帳號 | 2026-11-17　更換：@alice 改成 @carol.tw |

## 5. 如何檢查

第 4 段的右欄。

```
如何檢查
這張證明是在持卡人的裝置上算出來的，永久公布在證明紀錄裡。看一個帳號有沒有台灣人背書，要看哪幾個地方、小心哪些手法：

如何檢查 Threads 帳號的島民證明
```

第一行是小標。「如何檢查 Threads 帳號的島民證明」是連結，連到「如何檢查 Threads 帳號的島民證明」那一頁（`check.md`，`/check`）。全部收回之後（第 6 段）、短編號對到兩張以上時（第 7 段）也是這一段，連到同一頁。全頁只有這一個入口；頁面不顯示「驗證通過」這類的字，不顯示完整的島民編號。想自己重算證明紀錄的人，從那一頁的最後一條到「如何驗證證明紀錄」（`verify.md`）。

## 5a. 換一張自己的

第 5 段之後、頁尾之前。不在第一屏。

```
一張自然人憑證可以換一張 Threads 的島民證明，上面寫著你的 Threads 帳號。

[ 我也要換島民證明 ]
〈需要什麼〉
```

「我也要換島民證明」是按鈕，連到過卡的第 1 步（`/proof`）。`〈需要什麼〉` 是 `home.md` 的〈需要什麼〉那一句，只寫在那裡；之後要改，只改那一處。

和第 5 段一樣，全頁只放一次。

## 6. 全部收回之後

這張自然人憑證收回了所有帳號時：

```
第 128 張島民證明

這張自然人憑證現在沒有把名額給任何帳號

上次過卡：3 天前（2026-11-15）
那一天收回了 Threads 的 @alice。
```

標題上方那一行和第 1 段相同：收回不改變順序號碼。沒有第 1 段的帳號和範圍那一句，沒有第 3 段；第 4、5 段照常。標題和「上次過卡」在第 1、2 段的位置（桌機的左欄），右欄空著。「上次過卡」那一行和標題一樣顯眼。第 2 段的那一段小字和「我要更新這張證明」不顯示，只有「那一天收回了 Threads 的 @alice。」那一行小字。收回的帳號只出現在小字那一行，不放大。

## 7. 短編號對到兩張以上

網址的短編號對到兩張以上的自然人憑證時，最上面：

```
這個網址對到 2 張自然人憑證
它們的島民編號開頭 10 個字元碰巧相同，彼此沒有關聯。
```

下面每一張各放一份完整的內容（第 1 到 4 段，或第 6 段），照島民編號的字元順序排，每一張的排法和只有一張時相同。每一份上方一行寫出比較長的島民編號開頭，讓人分得出來：

```
島民編號 7K2Q9FM4XD3A 開頭
```

寫幾個字元：從 10 個字元起，加到這幾張互不相同為止。

第 5 段全頁只放一次，在最後一張的後面。

## 8. 連結被貼出去時的預覽

這一頁的連結貼到社群平台或通訊軟體時，預覽顯示：

```
標題：一張自然人憑證把 Threads 的名額給了 @alice
網站：島民證明 iamreal.tw
```

- 分頁的標題（`<title>`）是預覽的標題後面加「｜島民證明」：`一張自然人憑證把 Threads 的名額給了 @alice｜島民證明`；下面三種情況也一樣
- 不寫摘要
- 不放日期：平台會把預覽存很久
- 不放順序號碼：標題有帳號名稱，帶了號碼就等於把號碼放在帳號名稱旁邊
- 圖見下面「預覽圖」，上面沒有帳號名稱（原則 4：島民證明的樣子不能像平台的官方認證）
- 標題比頁面上的短，是為了帳號名稱不被截掉
- 預覽的文字要在送出頁面時就寫好
- 全部收回之後（第 6 段），標題是「這張自然人憑證現在沒有把名額給任何帳號」；短編號對到兩張以上時（第 7 段），標題是「這個網址對到 2 張自然人憑證」；對不到任何卡片時（第 9 段），標題是「找不到這張島民證明」

### 預覽圖

網站的每一頁都用同一張圖，這一頁也是；有預覽的頁面才有圖。圖和首頁同一層（`design/DESIGN.md`「兩層」），樣子照 `design/screens/og-image.png`：左邊是記號和下面的字，右邊是一片點，其中一個紅點是「你」。圖上沒有帳號名稱、日期、島民編號：平台會把圖存很久，而且每一頁都是同一張。

圖上的字，由上到下：

```
島民證明
即便是小國小民
也能一起讓網路的聲量更真實
iamreal.tw
```

替代文字：

```
島民證明：即便是小國小民，也能一起讓網路的聲量更真實。iamreal.tw
```

## 9. 短編號對不到任何卡片時

```
找不到這張島民證明

iamreal.tw/p/7K2Q9FM4XD 沒有對到任何一張自然人憑證。請確認網址有沒有抄錯。

如果你是從某個帳號的個人檔案點進來的，請留意這張島民證明並不存在。

查一個 Threads 帳號
```

- 網址那一行顯示的是訪客打開的網址
- 「查一個 Threads 帳號」是連結，連到證明紀錄頁（`proof-log-page.md`），停在查詢的那一欄
