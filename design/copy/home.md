# 首頁

`iamreal.tw`，網站的第一頁。看的人有兩種：想知道島民是什麼的訪客，和想換島民證明的持卡人。原則在 `docs/design/principles.md`。

- 稱呼用「你」
- 第一次上線只有 Threads，頁面上只寫 Threads
- 首頁的常見問題只列題目，答案的文字寫在 `faq.md`

例子裡的 `@alice`、`Threads`、`7K2Q9FM4XD`、`1,284`、`1,031`、天數是會換掉的值，其餘是固定的文字。

下面各段的順序就是頁面由上到下的順序。最後的「手機上打開時」那一塊不在首頁上，顯示在過卡第 1 步的最上面。

## 需要什麼

這一句在這一份只寫這一次。下面寫 `〈需要什麼〉` 的地方，就是放這一句：

```
需要實體的自然人憑證、讀卡機和電腦。
```

用到它的地方：第 1 段（第一屏）、第 8 段（結尾）。

之後有手機 app 時，只改這一處。到時要一起看的還有：第 4 段「怎麼換」第 1 步的說明（句子不同，寫在那一段）、「手機上打開時」那一塊，和 `faq.md` 裡提到讀卡機的句子。

## 導覽列

首頁最上面。

```
島民　　怎麼驗證　　名冊　　常見問題　　GitHub　　[ 我要換島民證明 ]
```

「島民」前面是記號，連到首頁。「怎麼驗證」連到 `verify.md` 那一頁；「名冊」連到 `roster-page.md` 那一頁；「常見問題」連到 `faq.md` 那一頁；「GitHub」連到公開的程式庫；「我要換島民證明」連到過卡的第 1 步（`card-proof.md`）。

## 1. 第一屏

```
島民　iamreal.tw

讓 Threads 上的人知道，你是真的台灣人。
用自然人憑證證明，除了 Threads 帳號名稱，不會揭露任何個資。

[ 我要換島民證明 ]　　看已經換出的島民證明
〈需要什麼〉

（縮小的島民證明）
```

- 「島民」和 `iamreal.tw` 排在一起
- 「我要換島民證明」是首頁唯一的主要動作，連到過卡的第 1 步。在手機上也一樣顯示、一樣連過去（見「手機上打開時」）
- 「看已經換出的島民證明」是連結，連到名冊頁（`roster-page.md`）
- `〈需要什麼〉` 緊接在按鈕下面一行

縮小的島民證明，內容照 `proof-page.md` 的說法：

```
島民證明　Threads
@alice
上次過卡　12 天前
島民編號　7K2Q9FM4XD 開頭
點進去看看 →
```

整張是連結，點進去是島民證明頁面的範例（還沒有）。

## 2. 數字

```
現在有 1,284 張島民證明
其中 1,031 張在過去三個月內過卡

每一張證明，背後都是一張自然人憑證。
```

- 只有一組數字，不分平台
- 第一個數字：現在把 Threads 的名額給了某個帳號的自然人憑證有幾張。收回了全部帳號的不算
- 第二個數字：第一個數字裡，上次過卡日在今天往回 90 天以內（含第 90 天）的有幾張；「今天」照台灣的日期。畫面只寫「過去三個月內」
- 兩個數字都列，從第一天就顯示，數字再小也照實寫，不設門檻
- 名冊頁（`roster-page.md`）和「怎麼驗證」的提示詞（`verify.md`）用的是同一個算法

## 3. 為什麼

```
留言區裡，
哪些是真的人？

社群平台上的假帳號越來越多，AI 只會讓假帳號更便宜、更像真人。靠每個人自己封鎖，只怕會是螳臂當車。

我們可以立場不同、支持不同的黨。但知道彼此是同一國的人，討論才有意義。

島民讓你不用告訴任何人你是誰，就能證明你是中華民國國民、證明你是台灣人。
```

前兩行是這一段的標題。

## 4. 怎麼換

```
怎麼換島民證明

1　準備自然人憑證
　　實體的卡片、讀卡機和電腦。
2　過卡
　　卡片簽下你的帳號，在你的裝置上算出一份證明。送出去的只有證明、帳號和島民編號。
3　掛到 Threads 的個人檔案上
　　把島民證明的連結放進個人檔案。掛上去，別人才看得出這個帳號承認這張證明。
```

- 第 1 步的說明和 `〈需要什麼〉` 講的是同一件事，之後有手機 app 時一起改
- 第 3 步連到把島民證明掛上個人檔案的那一頁（`hang.md` 第 2 部分）

## 5. 它證明了什麼

```
它證明了什麼

一張島民證明有兩半。

第一半　算得出來的
一張台灣實體自然人憑證，在 Threads 只能換一張島民證明。這一張證明上面寫給 @alice。
這一半任何人都可以驗證，不用相信我們。它是一份零知識證明：確認得了卡片是有效的，卻不用暴露卡片上的個資。

第二半　要自己看的
@alice 把這張證明的連結，掛在自己的個人檔案上。
這表示帳號主人承認這張島民證明。點連結進去，可以看到上次過卡是幾天前。

兩半都在，才是「@alice 說自己是島民」。
只有第一半，只代表有人拿卡片換了一張宣告 @alice 的島民證明，但看不出換的人是不是 @alice 的主人。
```

- 兩半各有一行小字：第一半是「這一半任何人都可以驗證……」，第二半是「這表示帳號主人承認……」
- 「零知識證明」是連結，連到「怎麼驗證」那一頁（`verify.md`）

接著是另一個標題的一段：

```
難以灌水

第一次申辦自然人憑證，要年滿 18 歲、本人到戶政事務所。

一張自然人憑證在 Threads 只能換一張。要一萬張島民證明，得先有一萬張真的自然人憑證。
```

第一句的來源：內政部《自然人憑證核發及管理作業要點》第四點（https://moica.nat.gov.tw/download/File/1000131.pdf）。寫「第一次申辦」，是因為到期換發可以線上辦。

## 6. 常見問題

```
常見問題

我的個資會外流嗎？
政府會知道我是哪個帳號嗎？
有島民證明，就代表不是網軍嗎？
別人可以換一張寫著我帳號的島民證明嗎？
卡片借人或賣給別人怎麼辦？
這個服務要錢嗎？
誰在做島民？

更多常見問題
```

七題，順序如上。每一題的答案和 `faq.md` 裡同一題的答案相同，文字只寫在 `faq.md`。「更多常見問題」是連結，連到常見問題那一頁。

## 7. 可以幫上什麼忙

```
所以島民可以幫上什麼忙？

現在　協助判斷一個 Threads 帳號背後是不是台灣人
　　　注意：還是有人會出售或出借自己的自然人憑證。
　　　有些話題，知道對方也是台灣人，才有得談。
現在　增加網軍建立假帳號的成本
現在　增加詐騙集團建立假帳號的成本
之後　分析一則貼文下面，留言裡有島民證明的比例
之後　需要一人一個帳號、又不想透露身分的場合
　　　例如連署、搶票、留言。
```

「現在」「之後」是每一項前面的標籤。

## 8. 結尾

```
假帳號要多少有多少。
你，只有一個。

站出來的台灣人越多，假帳號就越難假裝成「大家」。

[ 我要換島民證明 ]

還沒有自然人憑證？本人帶身分證到戶政事務所，250 元，當天拿到。任何一間戶政事務所都可以辦，不限戶籍地。
〈需要什麼〉島民只收台灣中華民國國民的自然人憑證正卡。
```

按鈕和第 1 段的相同，連到過卡的第 1 步。

「還沒有自然人憑證？」那一句的來源：內政部《自然人憑證核發及管理作業要點》第四點（https://moica.nat.gov.tw/download/File/1000131.pdf）和內政部行動自然人憑證常見問題（https://fido.moi.gov.tw/pt/main/qa）。上線前要對過內政部憑證管理中心的申辦說明：那個網站擋自動讀取，還沒有人對過原頁。

## 9. 頁尾

```
島民　iamreal.tw　　名冊　　GitHub　　怎麼準備　　常見問題
```

「名冊」「GitHub」「常見問題」連到的地方和導覽列相同。「怎麼準備」連到的說明還沒有（`card-proof.md` 第 2 步也有同一個連結）。

## 手機上打開時

不在首頁上。在手機上按了「我要換島民證明」，照常到過卡的第 1 步（`card-proof.md`「開始之前」）；那一頁在手機上最上面多這一塊，下面照常是「開始之前」：

```
過卡要在電腦上做
請在電腦的瀏覽器打開：
iamreal.tw
[ 複製網址 ]　[ 傳給自己 ]
```

- 「傳給自己」用手機內建的分享
- 只是提醒，不擋住：判斷是不是手機不一定準（例如平板接了讀卡機），真的不能過卡的裝置會在第 2 步「讀取卡片」停下並說明原因
- 之後有手機 app 時，這一塊換成下載 app 的入口

## 連結被貼出去時的預覽

```
標題：島民
網站：島民 iamreal.tw
摘要：讓 Threads 上的人知道，你是真的台灣人。用自然人憑證證明，除了 Threads 帳號名稱，不會揭露任何個資。
```

- 摘要是第 1 段第一屏的那兩行，接成一句
- 分頁的標題：`島民｜iamreal.tw`
