# 首頁

`iamreal.tw`，網站的第一頁。看的人有兩種：想知道島民證明是什麼的訪客，和想換島民證明的持卡人。原則在 `docs/design/principles.md`：首頁是首頁層（「首頁和事實頁」），可以用比較強的語氣，四條底線不能碰；常見問題那一段照事實頁寫。版面在 `design/DESIGN.md`，定稿的樣子是 `design/screens/home-desktop.png`、`home-phone.png`。

- 稱呼用「你」
- 第一次上線只有 Threads，頁面上只寫 Threads
- 首頁的常見問題，題目和答案都照 `faq.md` 同一題，文字只寫在 `faq.md`
- 示意圖裡的字（圖例、示意的畫面、圖說）和給螢幕閱讀器的說明，都寫在這一份。示意圖裡的點對螢幕閱讀器隱藏，整張由一句說明代替

例子裡的 `@alice`、`Threads`、`7K2Q9FM4XD`、`1,284`、`1,031` 是會換掉的值，其餘是固定的文字。第 2 段兩則貼文裡的數字（`428`、`2,316` 這些）是示意，固定不變。

下面各段的順序就是頁面由上到下的順序；一段裡的程式碼區塊，也是頁面上的順序。段落用小標的名稱找。最後的「手機上打開時」那一塊不在首頁上，顯示在過卡第 1 步的最上面。

## 需要什麼

這一句在這一份只寫這一次。下面寫 `〈需要什麼〉` 的地方，就是放這一句：

```
需要實體的自然人憑證，和手機，或讀卡機和電腦。
```

首頁只放一次，在「第一屏」。島民證明頁（`proof-page.md` 第 5a 段）也引用這一句。

之後要改，只改這一處。到時要一起看的還有：「結尾」怎麼換第 1 步的說明（句子不同，寫在那一段）、「手機上打開時」那一塊，和 `faq.md` 裡提到讀卡機的句子。

## 一起能改變什麼

```
我們一起，能改變什麼？

證明的人越多，
假扮台灣人的成本就越高。

每多一個人換一張島民證明，就多一個有島民證明的帳號。有證明的帳號越多，只靠假帳號堆出來的聲量就越顯得單薄，想操作輿論的人得付出更多。
```

兩個數字並排（手機上上下排），下面是比例條和它的圖例：

```
現在有
1,284
張島民證明

其中
1,031
張在過去三個月內過卡

過去三個月內過卡
超過三個月沒有過卡

每一張證明，背後都是一張自然人憑證。
```

- 只有一組數字，不分平台
- 第一個數字：現在把 Threads 的名額給了某個帳號的自然人憑證有幾張。收回了全部帳號的不算
- 第二個數字：第一個數字裡，上次過卡日在今天往回 90 天以內（含第 90 天）的有幾張；「今天」照台灣的日期。畫面只寫「過去三個月內」
- 兩個數字都列，從第一天就顯示，數字再小也照實寫，不設門檻
- 比例條的總長是第一個數字，藍綠那一段是第二個數字；第一個數字是 0 時整條都是底色。比例條和圖例對螢幕閱讀器隱藏：兩個數字已經寫出來了
- 證明紀錄頁（`proof-log-page.md`）和「如何驗證證明紀錄」的提示詞（`verify.md`）用的是同一個算法

接著是一片橫跨整個寬度的點，左邊稀疏、越往右藍綠的點越多，左邊有一個紅點是「你」。給螢幕閱讀器的說明，和紅點旁邊的標籤：

```
一大片留言的帳號，越往右，有島民證明的帳號越多；其中一個是你。
```

```
你
```

這一點不脈動：會自己動的只有第一屏的「你」。

```
現在
查一個帳號有沒有島民證明
其他服務可以建立在島民證明上。
任何人都能查閱一個帳號，看看是否有島民證明替其背書，如果有，可以檢查上次過卡更新是幾天前。
島民證明只代表有一個自然人憑證宣稱持有某帳號，至於帳號主人承不承認這張證明，要看他有沒有把連結掛在自己的個人檔案上。

任何專案都能夠建立

未來
```

三層，每一層依序是標籤、名稱、說明：

- 「現在」是地基（`design/DESIGN.md`「元件」）：淺藍綠底、藍綠實線框，排在最下面、撐滿寬度；「其他服務可以建立在島民證明上。」是它的小字

```
怎麼換

1　準備自然人憑證
　　實體的卡片，和支援 NFC 的手機（iPhone 或 Android 都可以）。用讀卡機和電腦也可以。
2　用卡片宣告你的帳號
　　過卡：輸入你的 Threads 帳號名稱，用卡片在你的裝置上算出證明。
3　拿到島民證明
　　過卡完成後，你會拿到這張證明的連結，任何人都能驗證：「有一張匿名的自然人憑證宣告自己持有某個 Threads 帳號」。
4　用你的帳號承認這張證明
　　把證明連結掛到 Threads 的個人檔案上。別人才看得出這個帳號承認這張證明（因為任何卡片都能宣告任何帳號，但一卡只能宣告一帳號）。

還沒有自然人憑證？本人帶身分證到戶政事務所，250 元，當天拿到。任何一間戶政事務所都可以辦，不限戶籍地。
我們只收台灣中華民國國民的自然人憑證正卡。非中華民國國籍人所持有的自然人憑證無法使用於島民證明。
```

- 第 4 步的「用你的帳號承認這張證明」連到把島民證明掛上個人檔案的那一頁（`hang.md` 第 2 部分的「從首頁點進來時」）
- 第 1 步的說明和 `〈需要什麼〉` 講的是同一件事，之後一起改
- 最後兩句是小字。「我們只收……」這兩句和過卡第 1 步（`card-proof.md`「開始之前」）寫的是同一句；`faq.md`「我不是中華民國國民，可以用嗎？」也要用同一種說法

「還沒有自然人憑證？」那一句的來源：內政部《自然人憑證核發及管理作業要點》第四點（https://moica.nat.gov.tw/download/File/1000131.pdf）和內政部行動自然人憑證常見問題（https://fido.moi.gov.tw/pt/main/qa）。上線前要對過內政部憑證管理中心的申辦說明：那個網站擋自動讀取，還沒有人對過原頁。

## 手機上打開時

不在首頁上。在手機上按了「我要換島民證明」，照常到過卡的第 1 步（`card-proof.md`「開始之前」）；那一頁在手機上最上面多這一塊，下面照常是「開始之前」：

```
過卡要在電腦上做
請在電腦的瀏覽器打開：
iamreal.tw
[ 複製網址 ]　[ 傳給自己 ]
```

- 「傳給自己」用手機內建的分享
- 只是提醒，不擋住：判斷是不是手機不一定準（例如平板接了讀卡機），真的不能過卡的裝置會在第 2 步「讀取卡片」停下並說明原因
