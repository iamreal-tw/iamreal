# 過卡需要什麼

「過卡需要什麼」那一頁，網址 `iamreal.tw/prepare`。每一頁的頁尾（`home.md` 第 9 段）和網頁過卡第 2 步停在「連不上內政部的元件」時（`card-proof.md` 第 2 步）連到這裡。原則在 `docs/design/principles.md`：這是事實頁。

- 稱呼用「你」
- 元件的正式名稱是「跨平台網頁元件」，這一頁寫正式名稱；過卡的畫面維持「內政部的元件」
- 對內政部的每一個說法都附來源，寫在那一段的下面；查不到來源的不寫
- 和過卡畫面重複的句子，和 `card-proof.md` 的相同：找不到讀卡機、彈出式視窗被擋、輸入錯三次會鎖住
- 每一段的程式碼區塊是頁面上的字；小標下面的粗體是那一項的名稱

下面第 1 到 4 段的順序就是頁面由上到下的順序。

## 2. 需要什麼

```
需要什麼

實體的自然人憑證
台灣中華民國國民的正卡。行動自然人憑證不能用。

晶片讀卡機
插得進自然人憑證的 USB 讀卡機。

Windows 或 macOS 的電腦
和一般的瀏覽器。

內政部的「跨平台網頁元件」
讓網頁能透過讀卡機和卡片溝通，裝在你的電腦上。

卡片的 PIN
自然人憑證的密碼。
```

第一行是小標。每一項第一行是名稱（粗體），第二行是說明。

- 「跨平台網頁元件」這個名稱：戶政司的說明「請使用者務必下載安裝跨平台網頁元件」；Mac 說明第 3 頁下載頁的截圖，標題「跨平台網頁元件下載」
- 只寫電腦：戶政司的說明「目前不支援行動裝置安裝」
- 「卡片的 PIN」不寫「辦卡時自己設定的」：申請資料表寫卡片有預設的密碼（「卡片密碼預設共8碼」「建議自行上網變更」）

## 3. 四個步驟

```
四個步驟

1　下載並安裝內政部的「跨平台網頁元件」
到內政部憑證管理中心的下載頁，選你的作業系統（Windows 或 macOS），照畫面安裝。安裝完成後，關掉所有網頁，再重新打開瀏覽器。

2　確認元件裝好了
Windows：「開始」的「所有程式」裡有「跨平台網頁元件」資料夾。macOS：打開「應用程式」裡的 HiPKILocalSignServer，上面寫「目前狀態為：開啟中」；寫「關閉中」的話，按「啟動HiPKILocalSignServer」。

3　接上讀卡機，插入自然人憑證
晶片朝讀卡機裡面插到底。

4　開始過卡
回到島民證明，按「我要換島民證明」。
```

第一行是小標。每一步第一行是編號和名稱（粗體），第二行是說明。「內政部憑證管理中心的下載頁」是連結，連到 `https://moica.nat.gov.tw/rac_plugin.html`。

- 下載頁的網址：Mac 說明第 3、20 頁的超連結都是 `https://moica.nat.gov.tw/rac_plugin.html`。這一頁本身擋自動讀取，沒有讀到
- 選作業系統、Windows 和 macOS 兩種：戶政司的說明「請依作業系統選取安裝」；Mac 說明第 3 頁下載頁的截圖有「下載Windows版」「下載Mac版」（還有 Linux 版，這一頁不寫：過卡沒有在 Linux 上試過）
- 「安裝完成後，關掉所有網頁，再重新打開瀏覽器」：Mac 說明第 3 頁下載頁的截圖「安裝完成後，請將電腦所有網頁關閉，再重新開啟瀏覽器」
- Windows 的「所有程式」：戶政司的說明寫，安裝完畢後，點選「開始」再點「所有程式」，「將會出現「HiCOS PKI Smart Card」及「跨平台網頁元件」等資料夾」
- macOS 的狀態和按鈕：Mac 說明第 5、6 頁。「應用程式」裡的那一個，說明的文字寫「HipkiLocalSignServer」，截圖上圖示下面的名稱是「HiPKILocalSignServer」，頁面照畫面上看得到的寫；視窗上寫「HiPKILocalSignServer目前狀態為：關閉中」或「：開啟中」，按鈕「啟動HiPKILocalSignServer」
- 沒寫的：Windows 上怎麼看元件有沒有在執行、怎麼啟動它，和「安裝完通常會自動啟動」「重新開機後要重新打開」，都查不到內政部的來源。內政部的兩份 PDF 沒有寫，Windows 的那一份只講彈出式視窗
- 第 3 步、第 4 步不是內政部的說法

## 4. 常見的狀況

```
常見的狀況

過卡時說「連不上內政部的元件」
元件沒有安裝，或沒有在執行。請照上面第 1、2 步確認，再回到過卡的畫面按「再讀一次卡片」。

過卡時說「找不到讀卡機」
請確認讀卡機已經接上電腦。換一個 USB 孔，或拔掉再接一次。

瀏覽器擋下了內政部元件的視窗
請按網址列右邊的「已封鎖彈出式視窗」，選「一律允許」這個網站，再按一次。

卡片被鎖住、忘了 PIN
PIN 連續輸入錯誤三次，卡片會被鎖住。請到內政部憑證管理中心的網站解鎖或重設 PIN。我們不知道你的 PIN，也沒辦法替你解鎖。

沒有讀卡機
現在只能用讀卡機過卡。之後會有「島民證明」app，用手機感應卡片，不需要讀卡機和元件。
```

第一行是小標。每一種狀況第一行是小標，第二行是說明。「內政部憑證管理中心的網站」是連結，連到 `https://moica.nat.gov.tw/`。

- 「連不上內政部的元件」「找不到讀卡機」「再讀一次卡片」和過卡畫面的字相同（`card-proof.md` 第 2 步）；「請確認讀卡機已經接上電腦。」是那一句的後半
- 「瀏覽器擋下了內政部元件的視窗」那一段，和過卡畫面的那一句相同（`card-proof.json` 的 `common.popup_blocked`）
- 「連續輸入錯誤三次，卡片會被鎖住」和過卡畫面的字相同（`card-proof.md` 第 3 步「PIN 不正確」）。來源：申請資料表「PIN碼輸入錯誤連3次遭鎖卡，使用【用戶代碼】即可立即解卡並重新設定卡片PIN碼。」
- 「解鎖或重設 PIN」：同一句；申請資料表的「用戶代碼」一欄也寫「卡片PIN碼忘記或被鎖卡……需輸入此資料，即可重新設定卡片PIN碼」。連到首頁，不連到解鎖的那一頁：那一頁的網址沒有讀到內政部的原文
- 「沒有讀卡機」：app 還沒有上架，所以寫「之後」。app 上架時，這一段改成「可以改用手機：下載「島民證明」app，用手機感應卡片，不需要讀卡機和元件。」，第 1 段加「用手機過卡只要手機和卡片，不用看這一頁。」，第 3 段第 4 步加「，選「我的電腦有讀卡機」」（`card-proof.json` 的 `app.use_reader`，網頁過卡的分路頁跟著 app 上線，#135）

最後一段下面不另外放東西，直接接頁尾（`home.md` 第 9 段）。
