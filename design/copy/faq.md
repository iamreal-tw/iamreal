# 常見問題

「常見問題」那一頁，導覽列上也叫「常見問題」。原則在 `docs/design/principles.md`。

除了「如何檢查 Threads 帳號的島民證明」（`check.md`）和「如何驗證證明紀錄」（`verify.md`），其他的說明都寫成這一頁的一題。別的頁面上的「了解更多」直接連到對應的那一題；每一題下面寫了哪個「了解更多」連到它。首頁的常見問題（`home.md`「常見問題」）用這一頁的八題，題目和答案都用這一頁同一題的文字；那八題下面寫了「首頁的常見問題有這一題」。

- 稱呼用「你」
- 四類，順序如下；每一類裡題目的順序就是頁面上的順序
- 每一類有固定的 `id`（英文），寫在那一類的名稱下面
- 每一題的題目是小標，下面的程式碼區塊是答案：空一行是分段，`·` 開頭是清單，`**…**` 是粗體，`[字](網址)` 是連結
- 常見問題要直接回答問題，不用「了解更多」「完整的說明」把人帶去站內的其他頁面或其他題。連結只留兩種：外部的資源（例如 GitHub、維護者的部落格），和連到某個功能的連結
- 每一題有固定的 `id`（英文），寫在那一題最下面；別的頁面的「了解更多」連到 `/faq#` 加上那個 `id`
- 每一題可以展開，一開始收起來，和首頁的常見問題（`home.md`「常見問題」）一樣：只看得到題目，點題目展開答案，再點一次收起。展開不需要程式，用鍵盤也按得到
- 連到某一題時，那一題展開，畫面捲到那一題：從別的頁面點進來、直接打開那個網址都一樣。連到分類（`#` 加上那一類的 `id`）只捲到那一類，不展開任何一題
- 最後一題下面不另外放東西，直接接頁尾（`home.md`「頁尾」）

## 關於隱私

這一類在頁面上的 `id`：`cat-privacy`。

### 我的個資會外流嗎？

```
你的姓名、身分證字號、自然人憑證和 PIN 都不會離開你的裝置。公開的證明紀錄會記下哪個社交帳號有島民證明，但對應不回是哪張卡片。

**注意：**拿到你的卡片和 PIN 的人，查得出你換過哪個帳號的島民證明，所以卡片請小心保管。
```

「注意：」是粗體。首頁的常見問題有這一題。

這一題在頁面上的 `id`：`personal-data`，連到這一題寫 `/faq#personal-data`。

### 政府會知道我是哪個帳號嗎？

```
從證明紀錄查不出來。Threads、政府、我們，都查不出一張島民證明是哪一張卡片換的。這也是只收實體卡片的原因。

但過卡時連線的 IP 位址會留 31 天，用來限制請求次數、擋下濫用、查問題。

這依賴於當前卡片的金鑰 (RSA 2048) 無法破解，不是永久的保證。
```

首頁的常見問題有這一題。

這一題在頁面上的 `id`：`government`，連到這一題寫 `/faq#government`。

### 島民證明服務安全嗎？

```
島民證明的程式碼全部公開在 [GitHub](https://github.com/iamreal-tw/iamreal)，任何人都能檢查：你的卡片資料是不是真的只留在你的裝置上、伺服器收到了什麼、證明是怎麼算出來的。

證明紀錄也是公開的。任何人都能用公開的程式，自己重新驗證每一張島民證明，不用相信我們。

公開程式碼不代表沒有漏洞。非常歡迎你到 GitHub 回報發現的問題。

有三件事要照實告訴你：

· 你的島民編號，是用卡片簽一段固定的文字算出來的，只有拿著卡片的人簽得出來。這把金鑰是卡片上的 RSA 2048 位元金鑰，也就是你用自然人憑證報稅時用的同一把。它目前沒有已知的破解方法，但沒有人能保證永遠如此（例如量子電腦出現突破性進展）。很多年後如果卡片的金鑰被破解，手上已經有你憑證的人（例如發卡的內政部），就能查出你換過哪個 Threads 帳號的島民證明。只看得到公開證明紀錄的人，還是查不出來。

· 網頁版的簽章會經過內政部的讀卡元件，和其他使用自然人憑證的網站一樣。元件看得到卡片簽出來的內容。我們沒有檢查過這個元件會不會留存或送出它。

· 這套算法由 Claude Fable 5.2 做過設計層面的檢查，還沒有外部的專家審查過。程式碼和規格都是公開的，你也可以自己檢查。
```

首頁的常見問題有這一題。

第一段的「GitHub」是連結，連到公開程式庫（https://github.com/iamreal-tw/iamreal）。

這一題在頁面上的 `id`：`security`，連到這一題寫 `/faq#security`。

### 營運者看得到什麼？

```
和證明紀錄裡公開的相同：Threads 帳號、島民編號、日期，還有那一份證明。你的姓名、身分證字號、自然人憑證和 PIN 都不會送到我們的伺服器。

除此之外，伺服器記下每個請求的時間、哪一個功能、成功或失敗和 IP 位址，保留 31 天後自動刪除，這是用來限制請求次數、擋下濫用與查問題。

頁面和 app 也會送出計數，例如打開了哪一種頁面、過卡走到哪一步，讓營運者知道用戶在哪裡卡住。計數帶著隨機的編號，最長一個月就會更換，所以營運者認不出一個月以前的你。網站不放 cookie，頁面上也沒有其他公司的分析或追蹤程式。
```

依據：ADR-0022（連線紀錄記 IP、留 31 天）、ADR-0032 和 ADR-0039（計數）。

這一題在頁面上的 `id`：`what-we-see`，連到這一題寫 `/faq#what-we-see`。

### 打開一張島民證明，Threads 會知道嗎？

```
會。

如果你在 Threads 裡點連結，網頁是用 Threads 內建的瀏覽器打開的，它是 Meta 的程式，看得到你打開了哪一頁。想避免的話，複製網址到你自己的瀏覽器打開。

此外，島民證明的頁面也會直接嵌入 Threads 帳號的個人檔案，所以 Threads 知道有人從你的 IP 位址看了這個帳號的個人檔案。如果這個瀏覽器登入著 Threads，它很可能也知道你是哪個帳號，在看哪個個人檔案。
```

隱私權說明的第 8 段「看島民證明的人」連到這一題（`privacy.md`）。

這一題在頁面上的 `id`：`threads-knows`，連到這一題寫 `/faq#threads-knows`。

## 它能證明什麼

這一類在頁面上的 `id`：`cat-what`。

### 有島民證明，就代表不是網軍嗎？

```
不是。它只代表有一張真的自然人憑證，把名額給了這個帳號。島民證明擋不住把自己卡片賣掉的台灣人，但它會讓假帳號的成本變得很高。

自然人憑證需要本人到戶政事務所申辦，一張 250 元。一張自然人憑證在 Threads 只能換一張，要建立一萬個有島民證明的帳號，得先有一萬張真的卡片。
```

「本人到戶政事務所申辦，一張 250 元」和「我還沒有自然人憑證，怎麼辦？」同一個來源：內政部《自然人憑證核發及管理作業要點》第四點（https://moica.nat.gov.tw/download/File/1000131.pdf）和內政部行動自然人憑證常見問題（https://fido.moi.gov.tw/pt/main/qa）。首頁的常見問題有這一題。

### 卡片借人或賣給別人怎麼辦？

```
拿到卡片和 PIN 的人就能產生一筆新的證明紀錄，我們無法判斷證明是否為持卡人產生。

但把自然人憑證交給別人，代價遠遠大過一張島民證明。它加上 PIN，就是你在網路上的身分證和印鑑：對方可以用你的名義報稅、查你的財產和所得資料、向政府申辦各種業務，簽出來的文件有法律效力。

別人看島民證明時，還會注意上次過卡是幾天前。卡片掛失之後，那張卡就不能再更新。
```

首頁的常見問題有這一題。

這一題在頁面上的 `id`：`lent-or-sold`，連到這一題寫 `/faq#lent-or-sold`。

### 為什麼要定期回來更新？

```
只有過卡的當下，才檢查得到自然人憑證在效期內、不在廢止清冊上。卡片之後遺失、被廢止、到了別人手上，證明紀錄都不會知道，要等下一次過卡。

惡意用戶可能會不斷「辦新卡，替某個帳號證明、掛失卡片」，掛失後的卡片無法更新島民證明，因此這些證明會呈現不再更新的狀態。而一般正常持卡人可以持續更新同一張島民證明。

我們不會寄信或傳訊息提醒你過卡。提醒只會來自你手機上的島民證明 app，而且是你自己設定的。
```

島民證明的頁面「上次過卡」那一段的「了解更多」連到這一題（`proof-page.md` 第 2 段現在還沒有這個連結）。

### 卡片遺失了，我的島民證明怎麼辦？

```
先去掛失。掛失之後那張卡片就不能再過卡。

舊的那一張島民證明還會留在證明紀錄裡，沒有人能把它拿掉，但它的上次過卡會停住，越來越舊。

補辦的新卡片是新的名額，可以重新換一張島民證明。記得把個人檔案上的證明連結更新。

### 島民證明上的「第 N 張」是什麼？

```
這張自然人憑證第一次留下有效的紀錄時，它是證明紀錄裡的第幾張卡片。你可以當成「第 N 張開始使用島民證明的卡片」。之後換帳號、收回再宣告、再次過卡，號碼都不變；換了新的自然人憑證會拿到新的號碼。
```

島民證明的頁面上標題上方那一行和「這張自然人憑證的證明紀錄」的「順序」（`proof-page.md` 第 1、4 段）寫的就是這個號碼；現在那兩處沒有連到這一題。號碼的算法在 `spec/record-rules.md`「The ordinal」。首頁的常見問題沒有這一題。

這種時候，請直接到 Threads 上看那個帳號的個人檔案有沒有這張島民證明的連結。

### 我改了 Threads 的名稱，島民證明會跟著改嗎？

```
不會。證明紀錄記的是你過卡時填的名稱，我們查不到 Threads 上的改動。請回來過卡，把帳號換成新的名稱；這會用掉一次更換額度，一張卡片最多可以更換 5 次。所有的更換紀錄都會公開。

本人帶身分證正本，到任何一間戶政事務所申辦，不限戶籍地。申請時要填一個電子郵件信箱。工本費 250 元，當天拿到卡片。

### 為什麼不能用行動自然人憑證？

```
實體卡片的簽章在卡片裡完成，只經過你的裝置。

行動自然人憑證的簽章要經過內政部的伺服器，內政部查得出是誰在使用；簽章流程還需要輸入身分證字號，我們就得經手不必要的個資。

而且行動自然人憑證的金鑰每年換一次，換手機也會換。島民編號是從金鑰算出來的，金鑰一換就是新的編號，一個人就能換好幾張島民證明。

基於上述考量，只能收實體的卡片。
```

第三段的來源：內政部行動自然人憑證常見問題。「申請與說明」（https://fido.moi.gov.tw/pt/main/qa）的「行動自然人憑證的最長使用年限與金鑰重新產製規定為何？」：每次簽發的金鑰效期 1 年，效期屆滿前要在 app 辦理金鑰重新產製。「應用問題」（https://fido.moi.gov.tw/pt/main/qa?level2id=20）的「如果要更換新行動裝置（手機或平板），怎麼轉移或綁定原有憑證？」：「無法沿用原有憑證」，要在新裝置重新註冊；同一頁錯誤碼 5003 那一題寫簽章金鑰在新裝置上產生。

這一題在頁面上的 `id`：`mobile-certificate`，連到這一題寫 `/faq#mobile-certificate`。

### 換錯帳號、想改、想拿掉怎麼辦？

```
當天發現帳號寫錯，可以當天回來過卡改掉。這叫更正，不算更換。

之後想換成別的帳號：可以，這叫更換。一張自然人憑證在 Threads 一共可以更換 5 次，用掉就不會恢復。所有的紀錄都會留在證明紀錄裡，讓大家查閱。

想拿掉：可以收回，收回不算更換。收回之後再換回同一個帳號，不算更換；換成別的帳號，算一次更換。

一張卡片一天最多過卡 3 次，避免一天內無限次更改。

所有操作紀錄會公開，而且無法刪除，這樣任何人才能驗證證明紀錄的有效性。
```

這一題寫更換的完整規則（`docs/design/principles.md`：過卡的畫面只寫還可以更換幾次，完整的規則寫在常見問題）：

- 把已經宣告的帳號改成別的帳號，算一次更換；第一次宣告不算
- 一張卡片在一個平台最多更換 5 次，用掉的次數不會恢復。每個平台各算，現在只有 Threads，所以寫「在 Threads」
- 同一天內，把當天才宣告或才更換的帳號再改掉，是更正，不另外算一次
- 收回不算更換；收回之後填回同一個帳號不算，填別的帳號算一次

這一題在頁面上的 `id`：`change-or-remove`，連到這一題寫 `/faq#change-or-remove`。

### 一張自然人憑證可以換幾張島民證明？

一張自然人憑證只能換一張證明，上面寫一個 Threads 帳號。你有兩個 Threads 帳號的話，只能選一個。
