# 名冊頁

「名冊」那一頁，導覽列上也叫「名冊」；首頁的「看已經換出的島民證明」連到這裡（`home.md` 第 1 段）。原則在 `docs/design/principles.md`。

四塊，由上到下：數字、查詢、清單、下載。

例子裡的 `@alice`、`@bob`、`Threads`、`7K2Q9FM4XD`、`3M8T1RZ6WA`、日期、`1,284`、`1,031` 是會換掉的值，其餘是固定的文字。「查」「更多」「下載整份名冊」「怎麼驗證」是按鈕或連結。

```
名冊

現在有 1,284 張島民證明，其中 1,031 張在過去三個月內過卡。

查一個 Threads 帳號
[ @              ]　[ 查 ]

最近換出的島民證明
列在這裡，只代表有一張自然人憑證把名額給了這個帳號。帳號主人承不承認，要點進那一張看。

2026-11-18　Threads 的 @alice　　島民編號 7K2Q9FM4XD 開頭
2026-11-17　Threads 的 @bob　　　島民編號 3M8T1RZ6WA 開頭
……
更多

下載整份名冊　　怎麼驗證
```

## 數字

和首頁第 2 段是同一組數字，算法見 `home.md` 第 2 段。

## 查詢

按「查」之後到那個帳號的查詢頁（`account-page.md`）。

## 清單

- 每一列只有文字：日期、帳號、島民編號的開頭。不放大頭貼，不嵌入個人檔案。每一列連到那一張島民證明
- 只列現在把名額給了某個帳號的卡片。收回了全部帳號的不列
- 每一列的日期，是這張卡片開始把名額給這個帳號的那一筆紀錄的日期（新宣告、更換、更正，或收回之後的再次宣告），和查詢頁的「從哪一天起」相同（`account-page.md`）。照這個日期排，新的在上。再次過卡不會改這個日期，也就不會讓一列回到最上面
- 日期只到天，不顯示時間
- 一次五十筆，其餘按「更多」
- 不做依帳號名稱的瀏覽或排序
- 「列在這裡，只代表……」那一句放在清單上方

## 下載

「下載整份名冊」下載公布的名冊；「怎麼驗證」連到 `verify.md` 那一頁。
