# 過卡

持卡人用一張自然人憑證換一張島民證明：把這張卡片的帳號清單公開記在證明紀錄裡，每個平台最多一個帳號。一次過卡處理整份清單（ADR-0017）：什麼都不改是再次過卡，填上空白的是新宣告，改掉已有的是更換，清空是收回。

網頁七步，一步一個畫面：開始之前、讀取卡片、輸入 PIN、你的帳號、確認、掛上去、完成和分享。app 在掛上去和完成之間多一步提醒，共八步。沒有選平台的畫面。卡片被要求做事的點擊有三次：讀取卡片、確認卡片、最後的確認；憑證讀一次，卡片簽兩次，PIN 輸入一次。

例子裡的 `@alice`、`@alice_tw`、`@bob`、`@carol.tw`、`Threads`、`X`、`test-example`、`alice-b`、日期、數字、`7K2Q9FM4XD`、`王小明` 是會換掉的值，其餘是固定的文字。「過卡需要什麼」連到網站的「過卡需要什麼」那一頁（`/prepare`，`prepare.md`）。例子裡的第二個平台 X 只用來示範清單有兩列的樣子；X 還沒有開放，它的帳號怎麼寫等平台表加入時才定。

這一份的文字各客戶端共用。標了「網頁」的句子只用在網頁上。

標了「app」的段落只用在 Android 和 iOS 的 app 上，換掉網頁在同一個位置的句子；沒有寫的地方照用共用的句子。app 上「這台裝置」「這台電腦」寫成「這支手機」。app 只認得 Threads，照「只有一個平台時」的規則用那幾句。app 的例子裡，`2027-03-01` 是最低版本的起算日（ADR-0035），`App Store` 在 Android 上是 `Google Play`。

更換的完整規則寫在常見問題的「換錯帳號、想改、想拿掉怎麼辦？」（`faq.md`）。

## 每個平台不同的東西

來自後台（`docs/api/card-proof.md`）：

- 這份證明紀錄收哪些平台（平台表，`GET /api/v1/config`）。第 4 步的清單就是這些平台，每個平台一列
- 每個平台這張卡片現在宣告的帳號、上一次宣告的帳號、更換過幾次（查這張卡片現況的回應）

寫死在裝置上，不從後台拿：

- 平台的顯示名稱（Threads）
- 帳號怎麼寫（Threads 是前面加 `@`）
- 哪些帳號名稱格式正確，和格式不對時的提示。提示是一句話，寫在這一份（下面）
- 預覽個人檔案開的網址（Threads 是 `https://www.threads.com/@名稱`）。沒有帳號公開頁面的平台，不顯示「預覽個人檔案」

帳號格式的字串（例如 Threads 的 `[a-z0-9._]{1,30}`）從後台的平台表拿；格式不對時的提示寫死在裝置上。

裝置認得、後台沒有列的平台，不出現在清單上。後台列了、裝置不認得的平台：這張卡片在那裡沒有帳號就不顯示；有帳號就顯示成不能修改的一列（第 4 步）。

格式不對時的提示，Threads：

```
帳號只能用英文小寫、數字、句點和底線，最多 30 個字。
```

### 只有一個平台時

後台的平台表上裝置認得的平台只有一個時，第 1、4、5、6、7 步有幾句換成只講一個帳號、寫出平台名稱的寫法（各步裡寫了是哪幾句；名稱是裝置自己的顯示名稱，例子是 Threads）。這張卡片在裝置不認得的平台上有帳號時，當成超過一個。

第 1 步還沒有平台表，也還不知道這張卡片的帳號，看的是裝置自己認得幾個平台。

## 每一步都有的

頁首是記號和服務的名稱。網頁的頁首和訪客的頁面一樣，名稱旁邊多寫網站的名字，不是連結；測試網站上也寫 `iamreal.tw`（`test-site.md`）：

```
島民證明
iamreal.tw
```

app 的頁首只有記號和服務的名稱。

每一步的畫面上方。網頁是共 7 步，app 是共 8 步，從第 1 步起都一樣：

```
第 2 步，共 7 步
```

回到前一個畫面和往下的按鈕：

```
[ 上一步 ]    [ 下一步 ]
```

讀取卡片和進行中的清單，每一項後面的狀態：

```
進行中……
完成
停在這裡
```

完成的項目前面打勾，用墨色，不用綠色；進行中的項目轉圈；停住的項目不打勾，原因寫在那一項下面。打勾只用在這兩張進度清單。

瀏覽器擋下了元件的視窗（三次點擊都可能發生；允許之後在同一步再按一次，不用從頭來）：

```
瀏覽器擋下了內政部元件的視窗。請按網址列右邊的「已封鎖彈出式視窗」，選「一律允許」這個網站，再按一次。
```

第 4 步和第 5 步有「取消」：丟掉 PIN，回到第 1 步。

```
取消
```

### app：感應的面板

三次感應由原本的三個按鈕叫出來：讀取卡片的「感應卡片」、輸入 PIN 的「確認卡片」、確認的「宣告這個帳號」「更新島民證明」或「收回對 @alice 的宣告」。面板上不寫這是第幾次感應。

iPhone 用系統的面板，app 只寫中間那一句：

| 面板的時候 | 畫面寫 |
|---|---|
| 等卡片 | 把自然人憑證貼在 iPhone 背面的上方 |
| 讀取憑證中 | 讀取中，不要移動卡片…… |
| 卡片簽章中 | 卡片簽章中，不要移動卡片…… |
| 讀到憑證 | 讀到了，可以拿開卡片 |
| 卡片簽好了 | 卡片簽好了，可以拿開卡片 |
| 感應沒有完成 | 沒有完成，請看 app 畫面上的說明。 |

「感應沒有完成」是卡片接上之後、讀到或簽好之前停下來的每一種情況：卡片中途離開、卡片回錯誤、安全通道建立不起來、第一代的卡片、不是同一張卡片、PIN 不正確。這時系統的面板要顯示成失敗的樣子，不是完成的勾：app 帶著這一句收起面板，原因照舊寫在那一步的畫面上（#367）。面板由系統自己收起來的時候不寫這一句，app 也寫不了：持卡人按面板的「取消」、面板等不到卡片、系統結束這一次感應（等太久、app 被切到背景）。

Android 由 app 自己畫一塊從下方出來的面板，寫同樣的事，多一句每支手機感應的位置不同。讀完之前，面板下面有「取消」。

```
把卡片貼在手機背面

自然人憑證平貼在手機背面的中間，不要移動。每支手機感應的位置不同，沒反應的話慢慢移動卡片找一下。

[ 取消 ]
```

| 面板的時候 | 標題 | 畫面寫 |
|---|---|---|
| 讀取憑證中 | 讀取中 | 讀取中，不要移動卡片…… |
| 卡片簽章中 | 讀取中 | 卡片簽章中，不要移動卡片…… |
| 讀到憑證 | 可以拿開卡片了 | 讀到了，可以拿開卡片 |
| 卡片簽好了 | 可以拿開卡片了 | 卡片簽好了，可以拿開卡片 |

感應停下來時，面板收起來（iPhone 的面板先顯示上面「感應沒有完成」那一句），原因寫在那一步的畫面上（各步的「app」）。在讀取卡片和輸入 PIN 的面板上按「取消」，回到按下之前的畫面，不寫原因；確認之後的面板見第 5 步。

裝置認得的平台不只一個時（「只有一個平台時」的相反），「非中華民國國籍者……」下面多兩段：

```
一張自然人憑證換一張島民證明，上面列出這張卡片宣告的帳號，每個平台最多一個。

```

「你宣告的帳號會公開列在……」那一段和上面幾行一樣顯眼，不收進可以展開的問題：知道了可能改變要不要繼續，公開之後收不回來。只有一個平台時沒有別的帳號可以列，這兩段不顯示：島民證明上寫什麼、會公開，在第 5 步確認的畫面講（原則 1：在做決定的那一刻說一次）。

這是第一個畫面，沒有「上一步」。

兩個可以展開的問題：

```
為什麼一定要實體的卡片？
實體卡片簽章在卡片裡完成，卡片效期約 5 ~ 8 年。
行動自然人憑證簽章依賴內政部伺服器，而且每年會更換金鑰，不適合作為島民證明使用。
```

- 卡片效期：憑證效期 5 年，可以展期；行動自然人憑證的最長使用年限「比照自然人憑證 IC 卡，為 8 年」（內政部行動自然人憑證常見問題，https://fido.moi.gov.tw/pt/main/qa ，「臨櫃申辦行動自然人憑證與自然人憑證 IC 卡申辦效期？」）
- 每年更換金鑰：「行動自然人憑證每次簽發之金鑰效期為1年」，到期前要在 app 裡「辦理金鑰重新產製」（同一頁，「行動自然人憑證的最長使用年限與金鑰重新產製規定為何？」；《內政部行動自然人憑證核發及管理作業要點》第六點：「行動自然人憑證效期為一年」）

```
還沒有自然人憑證，怎麼申辦？
本人攜帶身分證到戶政事務所臨櫃申辦，當場拿到卡片，費用 250 元。
[ 找附近的戶政事務所 ]
內政部憑證管理中心：如何申請自然人憑證（moica.nat.gov.tw）
```

申辦的那一句（臨櫃、當場拿到、250 元）上線前要對過內政部憑證管理中心的原文。

這一題的兩個連結是過卡畫面預設不連出去的例外（原則 1）：還沒有卡片的人過不了這一步，要知道去哪裡辦。兩個都在新分頁開，不帶任何過卡的資料：

- 「找附近的戶政事務所」：網頁開地圖網站的搜尋「戶政事務所」（Google 地圖的搜尋網址 `https://www.google.com/maps/search/?api=1&query=戶政事務所`，[Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)）；app 交給手機的地圖 app 搜尋同一個詞。網站和 app 都不拿位置：附近是地圖自己判斷的

### 停止收過卡時

營運者停止收過卡時（後台的 `config` 說 `paused`，ADR-0033、`docs/api/card-proof.md`），這一步一打開就問後台，在讀卡之前講：不讓持卡人插了卡、輸了 PIN 才知道。「下一步」換成這一句，沒有要按的按鈕：

```
現在暫停收過卡。已經換到的島民證明照常有效，證明紀錄也照常可以查。請晚點再來。
```

- 不寫什麼時候恢復、去哪裡看公告：營運者沒有公告的地方
- 問不到後台時照常顯示「下一步」：第 2 步「連上島民證明的伺服器」會再問一次，停止的話停在那裡
- app 和網頁同一句（app 的畫面另開票）

## 2. 讀取卡片

```

○ 連上島民證明的伺服器
○ 下載內政部的廢止清冊，確認憑證沒有被廢止

[ 上一步 ]    [ 讀取卡片 ]

```

## 4. 你的帳號

卡片簽完場合字串後停在這裡。這一步不碰卡片。

畫面照這張卡片的情況分成兩種（後台回的現況決定，裝置不另外判斷）：

- 這張卡片沒有任何宣告（沒宣告過，或全部收回過）：只有填帳號的欄位，填上的是新宣告

- 「在個人檔案添加證明連結……」是掛上去的理由，放在標題下面：任何人都能宣告任何帳號，系統確認不了帳號是不是持卡人的，所以第 4 步不講這件事，在這裡當成要掛上去的理由講（#357，原則 1：在做決定的那一刻說一次）
- 「用手機掛，最快」和「或在這台電腦上做」在桌機上左右並排
- 網頁的過卡畫面上是這四步的字；會動的示範在掛上去那一頁（下面「示範」、`hang.md`「示範」）
- QR code 的內容是這張島民證明掛上去的那一頁的網址（`hang.md` 第 2 部分）：`https://iamreal.tw/hang/7K2Q9FM4XD`，網域是這個網站的（測試網站是 `test.iamreal.tw`），只帶短編號，不含卡片上的任何資料。QR code 在這台裝置上產生，不向任何地方發請求
- 連結是這張卡片的島民證明的網址（`iamreal.tw/p/` 加 10 個字元的島民編號），所有平台用同一個；帳號改了，連結不變。「複製證明連結」複製的是帶 `https://` 的完整網址，按了之後按鈕寫「已複製」
- 「打開 @alice 的 Threads 個人檔案」連到帳號的公開頁面（`https://www.threads.com/@alice`），清單上每個有公開頁面的帳號一個
- 「打開你的島民證明」是連結，連到這張島民證明（`hang.md` 第 3 部分）
- 連到別的頁面的連結都在新分頁開：離開這一頁，過卡就結束了
- 沒有「上一步」：第 5 步已經送出，回不去了

平台表上裝置認得的平台不只一個時（「只有一個平台時」的相反），標題和下面那一句換成：

```
把證明掛上你的個人檔案
任何人都能宣告任何帳號。你把同一個連結掛上每個帳號的個人檔案，別人才知道那個帳號承認這張證明。
```

「如果你換了新的自然人憑證……」只在這張卡片的第一筆紀錄時顯示。

這次有帳號被收回、清單裡還有帳號時（平台不只一個），在「如果你換了新的自然人憑證……」的位置：

```
已經收回的帳號，個人檔案上的連結可以拿掉。
```

清單上有帳號也被別的卡片宣告時（後台回的 `account_cards` 大於 1），在同一個位置，每個這樣的帳號一句：

```
還有別的卡片也宣告了 @alice。任何持卡人都可以宣告任何帳號；帳號主人承認哪一張，看個人檔案上放的是哪一張的連結。
```

後台的回應裡讀不出每個平台記成什麼時，紀錄已經在證明紀錄裡，照完整的這一頁顯示；日期那一行下面多一句：

```
這一頁讀不出伺服器回報每個帳號記成什麼。打開這張島民證明，可以看到現在的清單。
```

### 證明紀錄記下的，和確認時畫面說的不同

後台回報每個平台記成什麼，和確認畫面那一列說的不同（種類不同、帳號不同，或一邊有那個平台另一邊沒有）時，第 6 步最上面（日期那一行之前）多一句，短版也換成完整的這一頁：

```
證明紀錄記下的，和你確認時畫面說的不同。請看下面標出來的地方。
```

「掛好了嗎？」那兩行下面，多一段證明紀錄記下的這一筆。只有這種時候顯示這一段。清單變成空的時沒有第 6 步，這一句和這一段在最後一步（「已全部收回」那一頁），位置相同：

```
證明紀錄記下了這一筆
2026-11-16
有一張有效的自然人憑證宣告了這份帳號清單：
  Threads    @alice
             新宣告
  X          @alice_tw
             新宣告
這張卡片的島民編號開頭是 7K2Q9FM4XD。
```

每一列下面是這次發生的事，句子和第 5 步「每一列下面寫會發生什麼」那張表相同；被收回的帳號也列在這裡。只有一個平台時，第一句換成：

```
有一張有效的自然人憑證宣告了這個帳號：
```

清單變成空的時，第一句是：

```
有一張有效的自然人憑證收回了所有帳號的宣告：
```

不同的那一列下面多一句，接確認畫面那一列原本的句子；確認畫面沒有這個平台時接「沒有這個平台」。後台記成更換、確認畫面說的不是更換時，再多一句：

```
確認時畫面說的是：更換，原本是 @alice。今天才宣告的帳號，這次改掉不另外算一次更換。
這次用掉了一次更換。
```

## 7. 提醒（只有 app）

網頁沒有這一步：第 6 步之後就是完成和分享（網頁的第 7 步）。提醒怎麼排、手機上存什麼、選間隔和時刻的畫面，在 `app.md`「過卡提醒」。例子裡的 `2027-02-08（星期一）`、`晚上 9:00` 照 `app.md`「日子和時刻」的寫法，`三個月` 是 `app.md` 的間隔（一個月、三個月、六個月），`2027-01-15` 是憑證的到期日。

依手機上存的提醒，有三種。

手機上沒有存提醒（第一次，或之前關掉了）：

```
提醒我回來過卡

建議定期更新島民證明，增加說服力。
這支手機會在 2027-02-08（星期一）晚上 9:00 提醒你，大約三個月後。

[ 上一步 ]    [ 開啟提醒 ]
改提醒間隔或時刻
這次不要
```

- 日子是今天起 12 週、晚上 9:00，「大約三個月後」照這個預設寫
- 按「開啟提醒」才向系統要通知的權限，允許了就照預設排，到第 8 步
- 「改提醒間隔或時刻」打開 `app.md` 的「選間隔和時刻」
- 「這次不要」什麼都不存，到第 8 步，下次過卡完成時再問。不顯眼，不說教

提醒開著：這次過卡完成就照上次的間隔和時刻重排，從今天起算，寫重排後的日子。按鈕是「上一步」「下一步」和「改提醒間隔或時刻」，沒有「這次不要」（要關掉從設定頁關）：

```
提醒我回來過卡

建議定期更新島民證明，增加說服力。
這支手機會在 2027-02-08（星期一）晚上 9:00 提醒你，大約三個月後。

[ 上一步 ]    [ 下一步 ]
改提醒間隔或時刻
```

在這一步按了「開啟提醒」，系統不允許這個 app 發通知時，什麼都不存：

```
提醒我回來過卡

沒有排提醒：手機不允許這個 app 發通知。請允許通知設定，我們不會在沒有經過你同意的情況下打擾你。

[ 上一步 ]    [ 打開通知設定 ]
這次不要
```

- 「打開通知設定」直接開到系統裡這個 app 的通知設定頁。回到 app 時再查一次：允許了就照預設排好，畫面換成提醒開著的那一個

「選間隔和時刻」選了日期、還沒有再過卡的時候，那一句不寫多久之後：

```
這支手機會在 2027-02-08（星期一）晚上 9:00 提醒你。
```

這張卡片的憑證在提醒的日子之前就到期時，日子那一句的下面多一句。比的是記憶體裡這張卡片的憑證的到期日，到期日不存進手機，通知也不提：

```
這張自然人憑證在 2027-01-15 到期，比下次提醒早。到期之後要展期或換新卡，才能再過卡。
```

- 還沒展期過的可以展期，展期過的要換新卡（#93）；app 怎麼分出這兩種還沒有定（#151），這一句兩種都適用
- 第一次問的時候比預設的日子，提醒開著時比排好的日子；到期日比那一天早才寫。沒有排提醒（權限被拒絕）時不寫

「上一步」回到第 6 步。

## 8. 完成和分享

網頁是第 7 步。這一段是號召的地方，照首頁的規則寫，可以用情感（`docs/design/principles.md`「首頁和事實頁」）：持卡人已經做完決定，要做的只剩要不要分享。

```
恭喜你完成島民證明

  島民證明
  @alice
  島民編號 7K2Q9FM4XD 開頭

這是第 128 張島民證明。愈多人成為島民，知道彼此都是台灣人，我們能讓台灣的網路討論變得更貼近真實、更有意義。
謝謝你加入島民，誠摯的邀請你分享島民證明。

[ 分享到 Threads ]

記得每三個月回來過卡一次
越久沒過卡，說服力越低。每次過卡，島民證明上的日期就會更新成今天。

[ 上一步 ]    [ 完成 ]
```

- 小卡照連結預覽圖的風格：記號和「島民證明」，下面是帳號，最下面是島民編號（`design/DESIGN.md`「證明卡」）。記號是動畫：卡片滑進來，島從卡片後面站起來
- 小卡列的是這次之後這張卡片宣告的帳號。只有一個平台時只寫帳號；超過一個時每一列前面寫平台的名稱：

  ```
    島民證明
    Threads    @alice
    X          @alice_tw
    島民編號 7K2Q9FM4XD 開頭
  ```

- `128` 是這張卡片的順序號碼，後台在送出的回應裡給（`ordinal`，`spec/records-response.md`），寫法和島民證明頁相同：超過三位數時每三位加一個逗號（`第 1,284 張`）。回應裡讀不到或讀不懂號碼時（包括再送一次才從現況找到這一筆的時候），不寫「這是第 128 張島民證明。」，那一段從「愈多人成為島民」開始
- 「記得每三個月回來過卡一次」那兩行只有網頁有：app 在第 7 步排提醒
- 不要求分享：不分享也已經完成
- 「上一步」回到前一步：網頁回到第 6 步剛才看的那個畫面（短版，或按了「沒有看到連結，重新掛上」之後完整的那一個），app 回到第 7 步。這時 PIN、憑證和簽章都已經丟掉，往回走不會碰到卡片
- 「完成」回到第 1 步
- 「分享到 Threads」打開 Threads 的發文畫面，預先填好下面這段文字（Threads 的 web intent，`https://www.threads.com/intent/post?text=…`，見 Meta 的 [Web intents](https://developers.facebook.com/docs/threads/threads-web-intents) 說明）：

  ```
  我剛剛換了第 128 張島民證明，宣告本帳號背後是一名台灣人。
  iamreal.tw/p/7K2Q9FM4XD
  ```

  `128` 是同一個順序號碼。沒有號碼時，第一行換成：

  ```
  我剛剛換了一張島民證明，宣告本帳號背後是一名台灣人。
  ```

  第二行是這張島民證明的網址，帶 `https://`，網域是這個網站的（測試網站是 `test.iamreal.tw`）。兩行都放在 `text` 裡，不用 `url`（那是連結的附件，網址不一定出現在貼文的文字裡）

標題照這次過卡做了什麼：

| 這次過卡做了什麼 | 標題 |
|---|---|
| 這張卡片的第一筆紀錄 | 恭喜你完成島民證明 |
| 只有一個平台時，新宣告或再次宣告（收回過之後再宣告） | 恭喜你完成島民證明 |
| 每一列都不變（再次過卡） | 島民證明已更新 |
| 只有一個平台時，更換 | 島民證明換成 @carol.tw 了 |
| 平台不只一個，有新宣告、再次宣告、更換或收回，清單裡還有帳號 | 島民證明已更新 |
| 清單變成空的 | 已全部收回 |
| 後台的回應裡讀不出每個平台記成什麼 | 證明紀錄已經記下這次過卡 |

## 示範

過卡流程有兩處用會動的示範說明怎麼做（#369）：第 2 步卡片貼在手機哪裡（兩個 app），和第 6 步把連結掛到個人檔案（兩個 app；網頁的那一頁見 `hang.md`「示範」）。示範怎麼動寫在 `design/motion/`。兩個 app 的畫面換成示範之前（#373 到 #376），第 2 步還是上面的兩張示意圖、圖說和說明。

示範旁邊一顆按鈕，兩個字樣。按「停止」直接停在最後一格，按「再看一次」從頭再來，沒有暫停和繼續：

| 什麼時候 | 按鈕 |
|---|---|
| 示範還在動 | 停止 |
| 停了或動完了 | 再看一次 |

系統設定減少動態時示範照樣會動，看的人用這顆按鈕停下來。

整段示範對螢幕閱讀器是一個元素，讀下面的一句，不讀裡面的東西；第 6 步四步的字照常讀。掛上去的那一句寫的是 app 第 6 步的按鈕「複製證明連結」；網頁掛上去那一頁的按鈕是「複製連結」，那一頁的句子照它寫（`hang.md`「示範」）：

第 2 步換成示範之後，Android 的說明是下面這一句：每一支 Android 感應的位置不同，示範裡的卡片會上下移動，說明不能再寫「不要移動」。iPhone 的說明不變。

```
按「感應卡片」，再把自然人憑證平貼在手機背面。每支手機感應的位置不同：沒有反應就慢慢上下移動卡片，畫面變成「讀取中」就停住，直到畫面說可以拿開。
```
