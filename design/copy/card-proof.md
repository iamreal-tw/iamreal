# 過卡

持卡人把一張卡片在一個平台的名額宣告給一個帳號，再次過卡，更換，或收回宣告。先確認卡片，再選要做的事；三次點擊（`docs/design/principles.md`「輸入 PIN 之前的畫面」）。

例子裡的 `@alice`、`@bob`、`Threads`、日期、數字、`7K2Q9F`、`王小明` 是會換掉的值，其餘是固定的文字。「怎麼準備」「了解更多」「怎麼重驗」是連到說明的連結。

## 1. 輸入 PIN 之前

```
用你的自然人憑證，宣告你的 Threads 帳號

平台    Threads

請插入自然人憑證。
接下來會請你輸入 PIN，讓卡片簽章，查出這張卡片目前宣告的帳號。
在你確認之前，不會公開任何東西。

留在這台電腦
· PIN
· 姓名和憑證
· 卡片的簽章

卡片請自行保管、請勿出借給他人。
拿到你的卡片和 PIN 的人，查得出這張卡片宣告過的帳號。  了解更多

[ 讀取卡片 ]

你需要自然人憑證、讀卡機，以及這台電腦上安裝好的內政部元件。  怎麼準備
```

## 2. 確認卡片

讀到卡片之後，按鈕的位置換成：

```
已讀到卡片：王小明
（姓名只顯示在這裡，不會送出。）

PIN  [          ]
[ 確認卡片 ]
卡片會簽章一次，用來查這張卡片目前宣告的帳號。這一步還不會宣告。
```

過不了的卡停在這裡，不出現 PIN 欄位。原因只顯示在畫面上，不回報後台。

| 情況 | 畫面寫 |
|---|---|
| 連不上元件 | 連不上內政部的元件。請確認已經安裝並啟動。 怎麼準備 |
| 沒有卡片 | 讀卡機裡沒有卡片。 |
| 憑證過期 | 這張卡片的憑證在 2025-03-01 到期，不能過卡。 |
| 在廢止清冊上 | 這張卡片的憑證已經被廢止或暫時停用，不能過卡。 |
| 不是國民的正卡 | 這張卡片不是國民的自然人憑證正卡，不能過卡。 |
| 憑證的格式電路不接受 | 這張卡片的憑證格式目前不支援。 |
| 廢止清冊太舊 | 內政部的廢止清冊已經 5 天沒有更新，現在不能過卡。 |
| 電腦的日期和題目的日期不同 | 這台電腦的日期和伺服器不一致，請檢查電腦的時間。 |
| 卡片鎖住了 | 這張卡片已經被鎖住。請到內政部憑證管理中心的網站解鎖後再試。 |
| 卡片上讀不到憑證 | 這張卡片上讀不到憑證。請確認插的是自然人憑證。 |
| 憑證還沒生效 | 這張卡片的憑證從 2026-12-01 才生效，現在不能過卡。 |
| 憑證不是內政部簽發的 | 這張卡片的憑證不是內政部憑證管理中心簽發的，不能過卡。 |
| 讀卡或簽章時的其他錯誤 | 讀卡時發生錯誤（代碼 `X`）。請重新插卡再試一次。 |
| 拿不到可用的廢止清冊 | 現在拿不到可用的內政部廢止清冊，不能過卡。請稍後再試。（代碼 `X`） |
| 拿到的廢止清冊比這台電腦上次用過的舊 | 拿到的廢止清冊比這台電腦上次用過的舊，不能過卡。請稍後再試。 |
| 電路檔或參數檔下載失敗，或內容和預期的不同 | 這一頁需要的檔案下載失敗或內容不符，不能過卡。請重新整理再試。 |
| 伺服器沒有回應，或回應讀不懂 | 伺服器的回應不正確，現在不能過卡。請稍後再試。（代碼 `X`） |

卡片上有兩張都通過檢查的憑證時，用「這張卡片的憑證格式目前不支援。」

瀏覽器擋下了元件的視窗（任何一次點擊都可能發生；允許之後在同一步再按一次，不用從頭來）：

```
瀏覽器擋下了內政部元件的視窗。請按網址列右邊的「已封鎖彈出式視窗」，選「一律允許」這個網站，再按一次。
```

PIN 不正確（發生在「確認卡片」）：

```
PIN 不正確。連續輸入錯誤三次，卡片會被鎖住。
```

## 3. 這張卡片的現況和可以做的事

卡片簽完場合字串後停在這裡。這一步不碰卡片。

還沒宣告過：

```
這張卡片在 Threads 還沒有宣告過。

你的帳號    @ [            ]
一張卡片在 Threads 同一時間只能宣告一個帳號。

[ 下一步 ]

系統不會確認帳號是不是你的：任何持卡人都可以宣告任何帳號。
帳號主人把這筆宣告的連結放在自己的個人檔案上，才表示承認。  了解更多
```

已經宣告：

```
這張卡片目前宣告的是 @alice。
上次過卡是 12 天前。過去一年更換過 1 次，還可以更換 1 次。

[ 再次過卡 ]        把上次過卡的日期更新成今天
[ 改成別的帳號 ]    會用掉一次更換
[ 收回宣告 ]
```

更換次數用完時，「改成別的帳號」不能按，旁邊寫：

```
一年最多更換兩次，下一次可以更換是 2027-03-02。
```

收回過，目前沒有宣告：

```
這張卡片目前沒有宣告。上一次宣告的是 @bob，已經收回。

[ 宣告回 @bob ]      不算更換
[ 宣告別的帳號 ]     會用掉一次更換
```

更換次數用完時，「宣告別的帳號」不能按，旁邊寫同一句。

按「改成別的帳號」或「宣告別的帳號」之後，輸入帳號：

```
新的帳號    @ [            ]

[ 上一步 ]    [ 下一步 ]

系統不會確認帳號是不是你的：任何持卡人都可以宣告任何帳號。
帳號主人把這筆宣告的連結放在自己的個人檔案上，才表示承認。  了解更多
```

帳號的格式不對：

```
帳號只能用英文小寫、數字、句點和底線，最多 30 個字。
```

## 4. 後果

選好之後一律停在這裡，按下後卡片才簽第二次。

```
按下後，名冊會公開記下：
2026-11-16，有一張有效的自然人憑證宣告了 Threads 的 @alice，
連同一個查不出是誰的編號。

這會用掉一次更換，之後一年內還剩 1 次。

紀錄裡沒有姓名、身分證字號和憑證序號。平台、營運者、政府都查不出這是誰的卡片；
但拿到你的卡片和 PIN 的人，查得出你宣告過的帳號。

之後可以用同一張卡片收回宣告，或更換帳號（一年最多兩次）。
為了讓任何人都能重驗，所有紀錄都不能刪除。

[ 上一步 ]    [ 宣告給 @alice ]
```

「這會用掉一次更換……」那一行只在更換時出現。名冊記下的那一句和按鈕依選的事而定：

| 選的事 | 名冊會公開記下 | 按鈕 |
|---|---|---|
| 第一次宣告、宣告回同一個帳號 | 2026-11-16，有一張有效的自然人憑證宣告了 Threads 的 @alice， | 宣告給 @alice |
| 再次過卡 | 2026-11-16，有一張有效的自然人憑證宣告了 Threads 的 @alice， | 再次過卡 |
| 更換 | 2026-11-16，有一張有效的自然人憑證宣告了 Threads 的 @alice， | 改成 @alice |
| 收回 | 2026-11-16，有一張有效的自然人憑證收回了對 Threads 的 @alice 的宣告， | 收回對 @alice 的宣告 |

收回時，倒數第二段改成：

```
之後可以用同一張卡片再宣告。為了讓任何人都能重驗，所有紀錄都不能刪除。
```

## 5. 進行中

按下之後，同一個畫面依序顯示：

```
卡片簽章中……
正在這台電腦上計算，大約 10 到 30 秒。請不要關閉這一頁，也不要切到別的分頁。
送出中……
```

| 情況 | 畫面寫 |
|---|---|
| 停太久，題目過期 | 等太久了，請再按一次。卡片需要重新簽章。 |
| 送不出去 | 送出失敗，名冊沒有變動。 [ 再試一次 ] |
| 後台沒有接受 | 這次過卡沒有被接受（代碼 `root`），名冊沒有變動。 |
| 這台電腦算不出證明 | 這台電腦算不出證明。請關閉其他分頁再試，或換一個瀏覽器。 |
| 算出的證明沒有通過這一頁自己的檢查 | 算出的證明不正確，沒有送出。請再試一次。 |
| 卡片回的簽章用憑證驗不過 | 讀卡時發生錯誤（代碼 `X`）。請重新插卡再試一次。 |
| 內政部的廢止清冊超過 3 天沒有更新 | 內政部的廢止清冊已經 5 天沒有更新，現在不能過卡。 |

## 6. 完成

```
已宣告。

名冊第 138 筆：2026-11-16，有一張有效的自然人憑證宣告了 Threads 的 @alice。
這張卡片在 Threads 的編號開頭是 7K2Q9F。

· 建議每 1 到 3 個月再過卡一次，上次過卡的日期才不會變舊。
· 不用相信這一頁，你可以自己重驗。  怎麼重驗

現在可以拔出卡片。
```

第一行依這次的結果：「已宣告。」「已再次過卡。」「已改成 @alice。」「已收回。」收回時，名冊那一行是「名冊第 138 筆：2026-11-16，有一張有效的自然人憑證收回了對 Threads 的 @alice 的宣告。」，沒有「建議每 1 到 3 個月再過卡一次」那一行。
