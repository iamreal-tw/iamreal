# 過卡

持卡人用一張自然人憑證換一張島民證明：把這張卡片的帳號清單公開記在名冊上，每個平台最多一個帳號。一次過卡處理整份清單（ADR-0017）：什麼都不改是再次過卡，填上空白的是新宣告，改掉已有的是更換，清空是收回。

六步，一步一個畫面：開始之前、讀取卡片、輸入 PIN、你的帳號、確認、完成。沒有選平台的畫面。卡片被要求做事的點擊有三次：讀取卡片、確認卡片、最後的確認；憑證讀一次，卡片簽兩次，PIN 輸入一次。

例子裡的 `@alice`、`@alice_tw`、`@bob`、`@carol.tw`、`Threads`、`X`、`test-example`、`alice-b`、日期、數字、`7K2Q9FM4XD`、`王小明` 是會換掉的值，其餘是固定的文字。「怎麼準備」「了解更多」「怎麼驗證」是連到說明的連結。例子裡的第二個平台 X 只用來示範清單有兩列的樣子；X 還沒有開放，它的帳號怎麼寫等平台表加入時才定。

這一份的文字各平台的裝置共用。標了「網頁」的句子只用在網頁上。

最後一節是「了解更多」連過去的說明頁要用的文字。

## 每個平台不同的東西

來自後台（`docs/api/card-proof.md`）：

- 這份名冊收哪些平台（平台表，`GET /api/v1/config`）。第 4 步的清單就是這些平台，每個平台一列
- 每個平台這張卡片現在宣告的帳號、上一次宣告的帳號、更換過幾次（查這張卡片現況的回應）

寫死在裝置上，不從後台拿：

- 平台的顯示名稱（Threads）
- 帳號怎麼寫（Threads 是前面加 `@`）
- 哪些帳號名稱格式正確，和格式不對時的提示。提示是一句話，寫在這一份（下面）
- 預覽個人檔案開的網址（Threads 是 `https://www.threads.com/@名稱`）。沒有帳號公開頁面的平台，不顯示「預覽個人檔案」

帳號格式的字串（例如 Threads 的 `[a-z0-9._]{1,30}`）從後台的平台表拿；格式不對時的提示寫死在裝置上。

裝置認得、後台沒有列的平台，不出現在清單上。後台列了、裝置不認得的平台：這張卡片在那裡沒有帳號就不顯示；有帳號就顯示成不能修改的一列（第 4 步）。

格式不對時的提示，Threads：

```
帳號只能用英文小寫、數字、句點和底線，最多 30 個字。
```

### 只有一個平台時

後台的平台表上裝置認得的平台只有一個時，第 1、5、6 步有幾句換成只講一個帳號、寫出平台名稱的寫法（各步裡寫了是哪幾句；名稱是裝置自己的顯示名稱，例子是 Threads）。這張卡片在裝置不認得的平台上有帳號時，當成超過一個。

第 1 步還沒有平台表，也還不知道這張卡片的帳號，看的是裝置自己認得幾個平台。

## 3. 輸入 PIN

輸入 PIN 之前要講的三件事在這個畫面，PIN 欄位下面。

```
輸入 PIN

已讀到卡片
王小明
（姓名只顯示在這裡，不會送出。）

PIN  [          ]

· 卡片會簽章一次，用來查這張卡片目前宣告的帳號。這一步還不會宣告，在你確認之前，不會公開任何東西。
· PIN、姓名和憑證、卡片的簽章不會離開這台裝置。
· 拿到你的卡片和 PIN 的人，查得出這張卡片宣告過的帳號。卡片請自行保管、請勿出借給他人。  了解更多

[ 上一步 ]    [ 確認卡片 ]
```

「上一步」回到讀取卡片，要重新讀一次。

按下「確認卡片」之後，到清單出來之前，PIN 欄位和按鈕不能用，按鈕旁邊寫：

```
卡片簽章中，接著查這張卡片目前宣告的帳號……
```

PIN 不正確：

```
PIN 不正確。連續輸入錯誤三次，卡片會被鎖住。
```

PIN 含有 `+`、`%` 或英數符號以外的字元（不送給卡片）：

```
這一頁不支援含有 +、% 或非英數符號的 PIN。請先到內政部憑證管理中心的網站變更 PIN。
```

這一步也可能出現第 2 步那張表裡的「卡片鎖住了」「讀卡時的其他錯誤」「伺服器沒有回應，或回應讀不懂」，句子相同，寫在 PIN 欄位下面。後台回的現況讀不懂時（沒有平台的清單、讀不出上次過卡的日期、讀不出裝置認得的平台那一項），也是「伺服器沒有回應，或回應讀不懂」那一句：沒有現況就建不出清單，不往下。

## 4. 你的帳號

卡片簽完場合字串後停在這裡。這一步不碰卡片。

畫面是這張卡片的帳號清單：後台列的每個平台一列，寫著現在宣告的帳號，或空白。持卡人直接在清單上改：

- 什麼都不改，往下就是再次過卡
- 填上空白的，是在那個平台新宣告
- 把已有的帳號改成別的，是更換
- 把已有的帳號清空，是收回

不引導把每個平台都填滿：沒有「還有平台沒填」這類提示，空白的列不特別標示。

「預覽個人檔案」用連結在新分頁開平台上的頁面，過卡的頁面不嵌入、不載入平台的任何東西。

### 每一列下面的那一行

清單上每一列只寫這一列現在的次數和能不能改。完整的更換規則放在「了解更多」，文字在最後一節。

「還可以更換幾次」算的是名冊規則上還能做的次數：5 減掉已經更換的次數。

| 這一列的情況 | 畫面寫 |
|---|---|
| 這個平台沒有宣告過 | 還沒有宣告過。 |
| 有帳號，還沒有更換過 | 還沒有更換過，還可以更換 5 次。 |
| 有帳號，更換過 1 到 4 次 | 更換過 1 次，還可以更換 4 次。 |
| 帳號是今天才宣告或才更換的（接在次數那一句後面） | 今天才宣告的帳號，今天改掉不另外算一次更換。 |
| 收回過，現在空白（次數那一句接在後面） | 上一次宣告的是 @bob，已經收回。填回 @bob 不算更換。 |
| 更換過 5 次 | 已經更換 5 次，這個平台不能再更換。 |
| 不能再更換，這一列有帳號（接在原因後面） | 這一列不能改成別的帳號，可以清空。 |

## 「了解更多」用的文字

這一節是說明頁用的，不出現在過卡的畫面上。第 4 步「更換的次數有限，用掉就不會恢復。」後面的「了解更多」連到這一段。

更換的規則：

- 把一個平台上已經宣告的帳號改成別的帳號，算一次更換
- 一張卡片在一個平台最多更換 5 次。用掉的次數不會恢復
- 每個平台各算：在 Threads 更換，不會用掉別的平台的次數
- 同一天內，把當天才宣告或才更換的帳號再改掉，不另外算一次
- 第一次宣告、收回、收回之後填回同一個帳號，都不算更換
- 收回之後填的是別的帳號，算一次更換
