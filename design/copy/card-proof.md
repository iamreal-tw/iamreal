# 過卡

持卡人把一張卡片在一個平台的名額宣告給一個帳號，或收回宣告。五個畫面、三次點擊（`docs/design/principles.md`「輸入 PIN 之前的畫面」）。

例子裡的 `@alice`、`@bob`、`Threads`、日期、數字、`7K2Q9F`、`王小明` 是會換掉的值，其餘是固定的文字。「怎麼準備」「了解更多」「怎麼重驗」是連到說明的連結。

## 1. 輸入帳號

```
用你的自然人憑證，宣告你的 Threads 帳號

平台        Threads
你的帳號    @ [            ]

一張卡片在 Threads 同一時間只能宣告一個帳號。

[ 下一步 ]

你需要自然人憑證、讀卡機，以及這台電腦上安裝好的內政部元件。  怎麼準備

系統不會確認帳號是不是你的：任何持卡人都可以宣告任何帳號。
帳號主人把這筆宣告的連結放在自己的個人檔案上，才表示承認。  了解更多

已經宣告過，想收回宣告？  收回
```

## 2. 輸入 PIN 之前

```
請插入自然人憑證。
你正在把這張卡片在 Threads 唯一的名額宣告給
@alice
一年最多可以更換帳號兩次。

會公開                                        留在這台電腦
· 有一張有效的自然人憑證宣告了 Threads 的 @alice    · PIN
· 一個查不出是誰的編號                            · 姓名和憑證
· 今天的日期                                      · 卡片的簽章

卡片請自行保管、請勿出借給他人。
拿到你的卡片和 PIN 的人，查得出這張卡片宣告了 @alice。  了解更多

[ 讀取卡片 ]
```

讀到卡片之後，按鈕的位置換成：

```
已讀到卡片：王小明
（姓名只顯示在這裡，不會送出。）

PIN  [          ]
[ 確認卡片 ]
卡片會簽章一次，用來查這張卡片目前宣告的帳號。這一步還不會宣告。
```

過不了的卡停在這裡，不出現 PIN 欄位。原因只顯示在畫面上，不回報後台。

| 情況 | 畫面寫 |
|---|---|
| 連不上元件 | 連不上內政部的元件。請確認已經安裝並啟動。 怎麼準備 |
| 沒有卡片 | 讀卡機裡沒有卡片。 |
| 憑證過期 | 這張卡片的憑證在 2025-03-01 到期，不能過卡。 |
| 在廢止清冊上 | 這張卡片的憑證已經被廢止或暫時停用，不能過卡。 |
| 不是國民的正卡 | 這張卡片不是國民的自然人憑證正卡，不能過卡。 |
| 憑證的格式電路不接受 | 這張卡片的憑證格式目前不支援。 |
| 廢止清冊太舊 | 內政部的廢止清冊已經 5 天沒有更新，現在不能過卡。 |
| 電腦的日期和題目的日期不同 | 這台電腦的日期和伺服器不一致，請檢查電腦的時間。 |

PIN 不正確（發生在「確認卡片」）：

```
PIN 不正確。連續輸入錯誤三次，卡片會被鎖住。
```

## 3. 這張卡片的現況和後果

卡片簽完場合字串後一律停在這裡。第一句和按鈕依現況而定，其餘固定。

```
這張卡片還沒有宣告過。

按下後，名冊會公開記下：
2026-11-16，有一張有效的自然人憑證宣告了 Threads 的 @alice。

紀錄裡沒有姓名、身分證字號和憑證序號。平台、營運者、政府都查不出這是誰的卡片；
但拿到你的卡片和 PIN 的人，查得出你宣告過的帳號。

之後可以用同一張卡片收回宣告，或更換帳號（一年最多兩次）。
為了讓任何人都能重驗，所有紀錄都不能刪除。

[ 取消 ]    [ 宣告給 @alice ]
```

| 這張卡片 | 第一句 | 按鈕 |
|---|---|---|
| 還沒宣告過 | 這張卡片還沒有宣告過。 | 宣告給 @alice |
| 目前宣告的是 @alice | 這張卡片目前宣告的是 @alice，上次過卡是 12 天前。 | 再次過卡 |
| 目前宣告的是 @bob | 這張卡片目前宣告的是 @bob。改成 @alice 會用掉一次更換，之後今年還剩 1 次。 | 改成 @alice |
| 更換次數用完 | 這張卡片目前宣告的是 @bob。一年最多更換兩次，下一次可以更換是 2027-03-02。 | （只有取消） |

## 4. 進行中

按下之後，同一個畫面依序顯示：

```
卡片簽章中……
正在這台電腦上計算，大約 10 到 30 秒，請不要關閉這一頁。
送出中……
```

| 情況 | 畫面寫 |
|---|---|
| 停太久，題目過期 | 等太久了，請再按一次。卡片需要重新簽章。 |
| 送不出去 | 送出失敗，名冊沒有變動。 [ 再試一次 ] |
| 後台沒有接受 | 這次過卡沒有被接受（代碼 `root`），名冊沒有變動。 |

## 5. 完成

```
已宣告。

名冊第 138 筆：2026-11-16，有一張有效的自然人憑證宣告了 Threads 的 @alice。
這張卡片在 Threads 的編號開頭是 7K2Q9F。

· 建議每 1 到 3 個月再過卡一次，上次過卡的日期才不會變舊。
· 不用相信這一頁，你可以自己重驗。  怎麼重驗

現在可以拔出卡片。
```

第一行依這次的結果：「已宣告。」「已再次過卡。」「已改成 @alice。」「已收回。」

## 收回

從第一個畫面的「收回」進來，同樣的畫面和三次點擊，不同的地方：

- 不輸入帳號。卡片簽完場合字串後，從名冊查出目前宣告的帳號
- 「輸入 PIN 之前」的前兩行是「請插入自然人憑證。」「你正在收回這張卡片在 Threads 的宣告」；「會公開」的第一行是「有一張有效的自然人憑證收回了對某個帳號的宣告」；最後一句是「拿到你的卡片和 PIN 的人，查得出這張卡片宣告過的帳號。」
- 「這張卡片的現況和後果」的第一句和按鈕：

| 這張卡片 | 第一句 | 按鈕 |
|---|---|---|
| 目前宣告的是 @alice | 這張卡片目前宣告的是 @alice。 | 收回對 @alice 的宣告 |
| 目前沒有宣告 | 這張卡片目前沒有宣告任何帳號。 | （只有取消） |

  「名冊會公開記下」的那一行是「2026-11-16，有一張有效的自然人憑證收回了對 Threads 的 @alice 的宣告。」
