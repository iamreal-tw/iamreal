# 過卡

持卡人用一張自然人憑證，在一個平台換一張島民證明：把這張卡片在這個平台的名額宣告給一個帳號，再次過卡，更換，或收回宣告。

選平台之後是六步，一步一個畫面：開始之前、讀取卡片、輸入 PIN、選要做的事、確認、完成。卡片被要求做事的點擊有三次：讀取卡片、確認卡片、最後的確認（`docs/design/principles.md`「輸入 PIN 之前的畫面」）。

例子裡的 `@alice`、`@bob`、`@carol.tw`、`Threads`、日期、數字、`7K2Q9F`、`王小明` 是會換掉的值，其餘是固定的文字。「怎麼準備」「了解更多」「怎麼驗證」是連到說明的連結。

## 每個平台不同的東西

平台的名稱、帳號怎麼寫（Threads 是前面加 `@`）、哪些帳號名稱格式正確和對應的提示、帳號公開頁面的網址，集中成一份定義，畫面從那裡取。下面的例子是 Threads 的。沒有帳號公開頁面的平台，不顯示「預覽個人檔案」。

## 每一步都有的

頁首是記號和服務的名稱：

```
島民
```

六步的畫面上方：

```
第 2 步，共 6 步
```

回到前一個畫面和往下的按鈕：

```
[ 上一步 ]    [ 下一步 ]
```

讀取卡片和進行中的清單，每一項後面的狀態：

```
進行中……
完成
停在這裡
```

完成的項目前面打勾，用墨色，不用綠色；進行中的項目轉圈；停住的項目不打勾，原因寫在那一項下面。

瀏覽器擋下了元件的視窗（三次點擊都可能發生；允許之後在同一步再按一次，不用從頭來）：

```
瀏覽器擋下了內政部元件的視窗。請按網址列右邊的「已封鎖彈出式視窗」，選「一律允許」這個網站，再按一次。
```

第 4 步和第 5 步有「取消」：丟掉 PIN，回到選平台。

```
取消
```

## 選平台

```
要換哪個平台的島民證明？

[ Threads  › ]
  X          還沒開放

一張自然人憑證在每個平台可以各換一張島民證明，各平台的島民編號不一樣。
```

還沒開放的平台列在上面，不能選。

## 1. 開始之前

```
開始之前

請準備好你的實體自然人憑證。
島民只收台灣中華民國國民的自然人憑證正卡。外來人口申辦的自然人憑證不能用。

[ 我的電腦有讀卡機  › ]
[ 我要用手機  › ]

▸ 為什麼一定要實體的卡片？
▸ 還沒有自然人憑證，怎麼申辦？

[ 上一步 ]
```

兩個可以展開的問題：

```
為什麼一定要實體的卡片？
實體卡片的簽章在卡片裡完成，只經過你的裝置。
行動自然人憑證的簽章要經過內政部的伺服器，內政部查得出是誰在使用；流程還要你輸入身分證字號，島民就得經手不必要的個資。所以只收實體的卡片。
```

```
還沒有自然人憑證，怎麼申辦？
本人攜帶身分證到戶政事務所臨櫃申辦，當場拿到卡片，費用 250 元。
內政部憑證管理中心的說明（moica.nat.gov.tw）
```

申辦的那一句（臨櫃、當場拿到、250 元）上線前要對過內政部憑證管理中心的原文。

超過 5 分鐘沒有完成而回到這個畫面時，在最上面：

```
超過 5 分鐘沒有完成，為了不讓 PIN 留在這一頁太久，已經回到開頭。請再讀一次卡片。
```

在手機上按「我的電腦有讀卡機」：

```
用讀卡機過卡要在電腦上做。請在電腦的瀏覽器自己輸入 iamreal.tw。
```

按「我要用手機」，在電腦上：

```
用手機過卡

用手機感應自然人憑證，不需要讀卡機。

（QR code）
用手機的相機掃這個 QR code，下載「島民」app。接下來的步驟都在 app 裡完成。
現在就是用手機在看這一頁？  直接下載「島民」app

[ 上一步 ]
```

在手機上：

```
用手機過卡

用手機感應自然人憑證，不需要讀卡機。

[ 下載「島民」app ]
接下來的步驟都在 app 裡完成。

[ 上一步 ]
```

QR code 只用來下載 app，不帶入帳號或任何過卡的資料。

**app 推出之前**，這一步不顯示選裝置的兩個按鈕和「用手機過卡」的畫面，「上一步」旁邊是「下一步」，直接到讀取卡片。

## 2. 讀取卡片

```
讀取卡片

請插入自然人憑證，再按「讀取卡片」。

○ 連上內政部的元件
○ 找到讀卡機和卡片
○ 讀取卡片上的憑證
○ 檢查憑證
○ 連上島民的伺服器
○ 下載內政部的廢止清冊，確認憑證沒有被廢止

[ 上一步 ]    [ 讀取卡片 ]
```

按下「讀取卡片」之後，清單由上到下一項一項變成「進行中……」再變成「完成」。全部完成後，「讀取卡片」換成「下一步」。

過不了的卡停在這裡，不到輸入 PIN 的畫面。停住的那一項寫「停在這裡」，原因寫在它下面，「讀取卡片」換成：

```
[ 再讀一次卡片 ]
```

原因只顯示在畫面上，不回報後台。

| 停在哪一項 | 情況 | 畫面寫 |
|---|---|---|
| 連上內政部的元件 | 連不上元件 | 連不上內政部的元件。請確認已經安裝並啟動。 怎麼準備 |
| 找到讀卡機和卡片 | 找不到讀卡機 | 找不到讀卡機。請確認讀卡機已經接上電腦。 |
| 找到讀卡機和卡片 | 沒有卡片 | 讀卡機裡沒有卡片。 |
| 讀取卡片上的憑證 | 卡片上讀不到憑證 | 這張卡片上讀不到憑證。請確認插的是自然人憑證。 |
| 讀取卡片上的憑證 | 讀卡時的其他錯誤 | 讀卡時發生錯誤（代碼 `X`）。請重新插卡再試一次。 |
| 讀取卡片上的憑證 | 卡片鎖住了 | 這張卡片已經被鎖住。請到內政部憑證管理中心的網站解鎖後再試。 |
| 檢查憑證 | 憑證過期 | 這張卡片的憑證在 2025-03-01 到期，不能過卡。 |
| 檢查憑證 | 憑證還沒生效 | 這張卡片的憑證從 2026-12-01 才生效，現在不能過卡。 |
| 檢查憑證 | 不是國民的正卡 | 這張卡片不是國民的自然人憑證正卡，不能過卡。 |
| 檢查憑證 | 憑證不是內政部簽發的 | 這張卡片的憑證不是內政部憑證管理中心簽發的，不能過卡。 |
| 檢查憑證 | 憑證的格式電路不接受 | 這張卡片的憑證格式目前不支援。 |
| 檢查憑證 | 讀到兩張都通過檢查的憑證 | 讀到兩張可以過卡的自然人憑證。請只留下要用的那一張，再讀一次。 |
| 連上島民的伺服器 | 電路檔或參數檔下載失敗，或內容和預期的不同 | 這一頁需要的檔案下載失敗或內容不符，不能過卡。請重新整理再試。 |
| 連上島民的伺服器 | 伺服器沒有回應，或回應讀不懂 | 伺服器的回應不正確，現在不能過卡。請稍後再試。（代碼 `X`） |
| 連上島民的伺服器 | 這台裝置啟動不了算證明的程式 | 這台電腦算不出證明。請關閉其他分頁再試，或換一個瀏覽器。 |
| 下載內政部的廢止清冊…… | 拿不到可用的廢止清冊 | 現在拿不到可用的內政部廢止清冊，不能過卡。請稍後再試。（代碼 `X`） |
| 下載內政部的廢止清冊…… | 廢止清冊太舊 | 內政部的廢止清冊已經 5 天沒有更新，現在不能過卡。 |
| 下載內政部的廢止清冊…… | 拿到的廢止清冊比這台電腦上次用過的舊 | 拿到的廢止清冊比這台電腦上次用過的舊，不能過卡。請稍後再試。 |
| 下載內政部的廢止清冊…… | 在廢止清冊上 | 這張卡片的憑證已經被廢止或暫時停用，不能過卡。 |

## 3. 輸入 PIN

輸入 PIN 之前要講的三件事在這個畫面，PIN 欄位下面。

```
輸入 PIN

已讀到卡片
王小明
（姓名只顯示在這裡，不會送出。）

PIN  [          ]

· 卡片會簽章一次，用來查這張卡片目前宣告的帳號。這一步還不會宣告，在你確認之前，不會公開任何東西。
· PIN、姓名和憑證、卡片的簽章不會離開這台裝置。
· 拿到你的卡片和 PIN 的人，查得出這張卡片宣告過的帳號。卡片請自行保管、請勿出借給他人。  了解更多

[ 上一步 ]    [ 確認卡片 ]
```

「上一步」回到讀取卡片，要重新讀一次。

按下「確認卡片」之後，到現況出來之前，PIN 欄位和按鈕不能用，按鈕旁邊寫：

```
卡片簽章中，接著查這張卡片目前宣告的帳號……
```

PIN 不正確：

```
PIN 不正確。連續輸入錯誤三次，卡片會被鎖住。
```

PIN 含有 `+`、`%` 或英數符號以外的字元（不送給卡片）：

```
這一頁不支援含有 +、% 或非英數符號的 PIN。請先到內政部憑證管理中心的網站變更 PIN。
```

這一步也可能出現第 2 步那張表裡的「卡片鎖住了」「讀卡時的其他錯誤」「伺服器沒有回應，或回應讀不懂」，句子相同，寫在 PIN 欄位下面。

## 4. 選要做的事

卡片簽完場合字串後停在這裡。這一步不碰卡片。

上次過卡是同一天時，寫「上次過卡是今天。」，不寫「0 天前」。

還沒宣告過：

```
選要做的事

這張卡片在 Threads 還沒有宣告過。

你的帳號    @ [            ]    [ 預覽個人檔案 ]
預覽會在新分頁開 Threads 上這個帳號的頁面，讓你確認沒有打錯。
一張卡片在 Threads 只能宣告一個帳號，一年內最多更換帳號兩次。

[ 下一步 ]

系統不會確認帳號是不是你的：任何持卡人都可以宣告任何帳號。
帳號主人把這筆宣告的連結放在自己的個人檔案上，才表示承認。  了解更多

取消
```

「預覽個人檔案」用連結在新分頁開平台上的頁面，過卡的頁面不嵌入、不載入平台的任何東西。

已經宣告：

```
這張卡片目前宣告的是 @alice。
上次過卡是 12 天前。過去一年更換過 1 次，還可以更換 1 次。

[ 再次過卡 ]        把上次過卡的日期更新成今天
[ 改成別的帳號 ]    會用掉一次更換
[ 收回宣告 ]
```

更換次數用完時，第二行寫：

```
上次過卡是 12 天前。過去一年更換過 2 次，不能再更換。
```

「改成別的帳號」不能按，下面那一行換成：

```
一年最多更換兩次，下一次可以更換是 2027-03-02。
```

收回過，目前沒有宣告：

```
這張卡片目前沒有宣告。
上一次宣告的是 @bob，已經收回。

[ 宣告回 @bob ]      不算更換
[ 宣告別的帳號 ]     會用掉一次更換
```

更換次數用完時，「宣告別的帳號」不能按，下面那一行換成同一句。

這張卡片今天在這個平台已經有 3 筆有效的紀錄時（上次過卡是今天，而且那天已經 3 筆），現況的那幾行照樣顯示，可以做的事換成這一句；按鈕只有「回到開頭」，和「取消」一樣丟掉 PIN、回到選平台：

```
這張卡片今天在 Threads 已經過卡 3 次，明天才能再過卡。

[ 回到開頭 ]
```

按「改成別的帳號」或「宣告別的帳號」之後，輸入帳號：

```
新的帳號

新的帳號    @ [            ]    [ 預覽個人檔案 ]
預覽會在新分頁開 Threads 上這個帳號的頁面，讓你確認沒有打錯。

[ 上一步 ]    [ 下一步 ]

系統不會確認帳號是不是你的：任何持卡人都可以宣告任何帳號。
帳號主人把這筆宣告的連結放在自己的個人檔案上，才表示承認。  了解更多

取消
```

帳號的格式不對（按「下一步」或「預覽個人檔案」時）：

```
帳號只能用英文小寫、數字、句點和底線，最多 30 個字。
```

## 5. 確認

選好之後一律停在這裡，按下後卡片才簽第二次。

```
確認

按下後，名冊會公開記下：

  有一張有效的自然人憑證宣告了 Threads 的這個帳號：
  @alice
  日期        2026-11-16
  島民編號    7K2Q9F 開頭

這會用掉一次更換，之後還可以再更換 1 次。

· 紀錄裡沒有姓名、身分證字號和憑證序號。平台、營運者、政府都查不出這是誰的卡片；但拿到你的卡片和 PIN 的人，查得出你宣告過的帳號。
· 之後可以用同一張卡片收回宣告，或更換帳號（一年最多兩次）。所有紀錄公開後無法刪除，這樣任何人才能驗證。

[ 上一步 ]    [ 宣告給 @alice ]
取消
```

「這會用掉一次更換……」那一行只在更換時出現。這次更換之後就用完時，寫：

```
這會用掉一次更換。下一次可以更換是 2027-03-02。
```

名冊記下的那一句和按鈕依選的事而定：

| 選的事 | 名冊會公開記下 | 按鈕 |
|---|---|---|
| 第一次宣告、宣告回同一個帳號 | 有一張有效的自然人憑證宣告了 Threads 的這個帳號： | 宣告給 @alice |
| 再次過卡 | 有一張有效的自然人憑證宣告了 Threads 的這個帳號： | 再次過卡 |
| 更換 | 有一張有效的自然人憑證宣告了 Threads 的這個帳號： | 改成 @alice |
| 收回 | 有一張有效的自然人憑證收回了對 Threads 的這個帳號的宣告： | 收回對 @alice 的宣告 |

收回時，第二點改成：

```
· 之後可以用同一張卡片再宣告。所有紀錄公開後無法刪除，這樣任何人才能驗證。
```

### 進行中

按下之後，還是第 5 步，換成這個畫面：

```
進行中

請不要關閉這一頁，也不要切到別的分頁。

○ 連上島民的伺服器
○ 卡片簽章
○ 在這台裝置上計算，大約 10 到 30 秒
○ 送出
```

計算的那一項進行中時，清單下面多一句：

```
正在算一份零知識證明：別人能確認這是一張有效的卡片，卻看不出是哪一張。  了解更多
```

停住時，原因寫在停住的那一項下面，清單下面出現按鈕。PIN 還在的情況（瀏覽器擋下視窗）是「回到上一步」，回到確認的畫面；其他情況 PIN 已經丟掉，按鈕是「再讀一次卡片」，回到讀取卡片。只有送不出去時多一個「再試一次」，只重做送出。

```
[ 回到上一步 ]
[ 再讀一次卡片 ]
[ 再試一次 ]
```

| 停在哪一項 | 情況 | 畫面寫 |
|---|---|---|
| 連上島民的伺服器 | 電腦的日期和題目的日期不同 | 這台電腦的日期和伺服器不一致，請檢查電腦的時間。 |
| 連上島民的伺服器 | 伺服器沒有回應，或回應讀不懂 | 伺服器的回應不正確，現在不能過卡。請稍後再試。（代碼 `X`） |
| 連上島民的伺服器 | 憑證在這段時間到期，或清冊在這段時間變得太舊 | 第 2 步那張表裡同一種情況的句子 |
| 卡片簽章 | 卡片回的簽章用憑證驗不過，或簽章時的其他錯誤 | 讀卡時發生錯誤（代碼 `X`）。請重新插卡再試一次。 |
| 卡片簽章 | 卡片鎖住了 | 這張卡片已經被鎖住。請到內政部憑證管理中心的網站解鎖後再試。 |
| 在這台裝置上計算 | 這台裝置算不出證明 | 這台電腦算不出證明。請關閉其他分頁再試，或換一個瀏覽器。 |
| 在這台裝置上計算 | 算出的證明沒有通過這一頁自己的檢查 | 算出的證明不正確，沒有送出。請再試一次。 |
| 送出 | 停太久，題目過期 | 等太久了，請再按一次。卡片需要重新簽章。 |
| 送出 | 送不出去 | 送出失敗，名冊沒有變動。 |
| 送出 | 後台沒有接受 | 這次過卡沒有被接受（代碼 `root`），名冊沒有變動。 |
