# 把島民證明掛到個人檔案

持卡人把島民證明的連結放上帳號的個人檔案（連回）。系統不確認有沒有放上去，訪客自己在島民證明的頁面上看（ADR-0003）。在電腦上過卡的人，可以改用手機把連結掛上去。

三部分：過卡完成畫面上的那一段、手機掃了之後的那一頁、掛好之後的那兩句。

例子裡的 `@alice`、`Threads`、`7K2Q9FM4XD` 是會換掉的值，其餘是固定的文字。

## 1. 過卡完成畫面上的那一段

在電腦上過卡完成時（`card-proof.md` 第 6 步）：

```
接下來：把它掛出來
用手機掃這個 QR code，照著做，一分鐘。

（QR code）

或在這台電腦上做：[ 複製連結 ]　打開 @alice 的 Threads 個人檔案
```

- QR code 的內容是這張島民證明的公開連結（`iamreal.tw/p/7K2Q9FM4XD`）加一個記號，不含卡片上的任何資料。手機掃了之後打開第 2 部分那一頁
- 「打開 @alice 的 Threads 個人檔案」是連結，連到 `https://www.threads.com/@alice`

這一段會取代 `card-proof.md` 第 6 步現在的「接下來：把它掛出來」那一段（見本檔最後「還沒做的」）。

## 2. 手機掃了之後的那一頁

```
把島民證明掛到 @alice 的個人檔案

[ 複製連結 ]　[ 打開 Threads ]

1　打開個人檔案按「編輯個人檔案」
（示意圖）
2　按「連結」貼上
（示意圖）
3　存檔
（示意圖）
```

- 「複製連結」複製這張島民證明的連結
- 每一步一張示意圖
- 首頁「怎麼換」第 3 步也連到這一頁（`home.md` 第 4 段）

## 3. 掛好之後

```
掛好了嗎？打開你的島民證明看看。頁面上的個人檔案裡看得到這個連結，就成功了。
```

島民證明的頁面嵌入了個人檔案（`proof-page.md` 第 3 段），持卡人在那裡親眼看到連結，就知道掛好了，也看到訪客看的是什麼。後台不讀 Threads（ADR-0003）。

## 還沒定的

- 電腦上的 Threads 網頁版能不能編輯個人檔案的連結，還沒實測。不能的話，第 1 部分「或在這台電腦上做」那一行拿掉
- 手機上按「打開 Threads」，開的是 Threads 的 app 還是瀏覽器、能不能直接到編輯個人檔案，還沒實測
- 之後在手機 app 上過卡時，完成的畫面直接給「複製連結」和「打開 Threads」，不用 QR code；那時的句子還沒寫

## 還沒做的
