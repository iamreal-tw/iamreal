# 把島民證明掛到個人檔案

持卡人把島民證明的連結放上帳號的個人檔案（連回）。系統不確認有沒有放上去，訪客自己在島民證明的頁面上看（ADR-0003）。在電腦上過卡的人，可以改用手機把連結掛上去。

三部分：過卡完成畫面上的那一段、手機掃了之後的那一頁、掛好之後的那兩行。

例子裡的 `@alice`、`Threads`、`7K2Q9FM4XD` 是會換掉的值，其餘是固定的文字。

## 1. 過卡完成畫面上的那一段

在電腦上過卡完成時（`card-proof.md` 第 6 步，句子以那裡為準）：

```
最後一步：掛到你的 Threads 個人檔案
任何人都能宣告任何帳號。你把連結掛上個人檔案，別人才知道這個帳號承認這張證明。

用手機掛，最快                          或在這台電腦上做
（QR code）                             iamreal.tw/p/7K2Q9FM4XD
用手機的相機掃這個 QR code，            [ 複製連結 ]
照著做，一分鐘。                        打開 @alice 的 Threads 個人檔案
                                        1　按「編輯個人檔案」
                                        2　按「連結」，貼上剛才複製的連結
                                        3　存檔

（第 3 部分的兩行）
```

- QR code 的內容是第 2 部分那一頁的網址：`https://iamreal.tw/hang/7K2Q9FM4XD`。只帶這張島民證明的短編號，不含卡片上的任何資料；網域是這個網站的（測試網站是 `test.iamreal.tw`）
- 「打開 @alice 的 Threads 個人檔案」是連結，連到 `https://www.threads.com/@alice`
- 電腦上的三步和第 2 部分的三步相同，少了「打開你的個人檔案」：上面那個連結就是
- 這一段的下面是第 3 部分的兩行

## 2. 手機掃了之後的那一頁

```
把島民證明掛到 @alice 的個人檔案

iamreal.tw/p/7K2Q9FM4XD
[ 複製連結 ]　[ 打開 Threads ]

1　打開你的個人檔案，按「編輯個人檔案」
（示意圖）
2　按「連結」，貼上剛才複製的連結
（示意圖）
3　存檔
（示意圖）

（第 3 部分的兩行）
```

- 標題下面、按鈕上面寫出這張島民證明的連結，不帶 `https://`，和島民證明頁面上的寫法相同（`proof-page.md` 第 3 段）。這樣沒有程式時（被擋、舊的瀏覽器）也看得到、選得起來
- 「複製連結」複製這張島民證明的完整連結，帶 `https://`：`https://iamreal.tw/p/7K2Q9FM4XD`。按了之後按鈕寫「已複製」
- 每一步一張示意圖
- 三步的下面是第 3 部分的兩行

### 從首頁點進來時

首頁「怎麼換」第 4 步也連到這一頁（`home.md`「結尾」）。這時沒有帶著一張島民證明，這一頁換成：

```
把島民證明掛到 Threads 的個人檔案

[ 打開 Threads ]

1　打開你的個人檔案，按「編輯個人檔案」
（示意圖）
2　按「連結」，貼上你的島民證明的連結
（示意圖）
3　存檔
（示意圖）

還沒有島民證明？　[ 我要換島民證明 ]
```

- 沒有「複製連結」，只有「打開 Threads」
- 「我要換島民證明」和首頁的按鈕相同，連到過卡的第 1 步
- 不顯示第 3 部分的兩行

## 3. 掛好之後的那兩行

```
掛好了嗎？打開你的島民證明看看。
頁面上的個人檔案裡看得到這個連結，就成功了。
```

- 顯示在兩個地方：第 2 部分那一頁三步的下面；第 1 部分過卡完成畫面「最後一步」那一段的下面
- 「打開你的島民證明」是連結，連到那一張島民證明（`iamreal.tw/p/7K2Q9FM4XD`）

島民證明的頁面嵌入了個人檔案（`proof-page.md` 第 3 段），持卡人在那裡親眼看到連結，就知道掛好了，也看到訪客看的是什麼。後台不讀 Threads（ADR-0003）。

## 連結被貼出去時的預覽

第 2 部分那一頁，帶著島民證明和從首頁點進來時都一樣：

```
標題：把島民證明掛到個人檔案
網站：島民證明 iamreal.tw
```

- 不寫摘要
- 分頁的標題是預覽的標題後面加「｜島民證明」：`把島民證明掛到個人檔案｜島民證明`

## 還沒定的

- 第 2 部分三步的示意圖：還沒有圖，三步現在只有文字
- 電腦上的 Threads 網頁版能不能編輯個人檔案的連結，還沒實測。不能的話，第 1 部分「或在這台電腦上做」那一欄拿掉
- 手機上按「打開 Threads」，開的是 Threads 的 app 還是瀏覽器、能不能直接到編輯個人檔案，還沒實測
- 之後在手機 app 上過卡時，完成的畫面直接給「複製連結」和「打開 Threads」，不用 QR code；那時的句子還沒寫
