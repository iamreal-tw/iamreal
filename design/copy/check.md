# 如何檢查 Threads 帳號的島民證明

「如何檢查 Threads 帳號的島民證明」那一頁，網址 `iamreal.tw/check`。給在 Threads 上看到一個帳號、想知道它有沒有台灣人背書的一般訪客。原則在 `docs/design/principles.md`：這是事實頁，原則 1–4 一字不放寬。

- 稱呼用「你」
- 重算整份證明紀錄的做法不寫在這裡，最後一條連到「如何驗證證明紀錄」（`verify.md`）
- 示意圖裡的名稱、網址、日期、張數是固定的例子，不是當天的資料
- 每一段的程式碼區塊是頁面上的字

下面第 1 到 4 段的順序就是頁面由上到下的順序。

## 1. 開頭

```
如何檢查 Threads 帳號的島民證明

在 Threads 上看到一個帳號，想知道有沒有一張台灣的自然人憑證替它背書，照下面四步看。不用安裝任何東西，也不用登入。
```

第一行是頁面的標題。

## 2. 四個步驟

```
四個步驟
```

第一行是小標。下面每一步一列：桌機左邊是編號（明體大字）、步驟名稱（小標題）、說明、「惡意手法」，右邊是那一步的示意圖；手機上文字在上、圖在下。

- 「惡意手法」預設折起來，點了才展開（`<details>`／`<summary>`，不用程式）。小標旁一個箭頭，展開時轉向，和首頁常見問題的箭頭同一種畫法；可點的高度至少 `--min-target`；上方一條細線和說明分開
- 不打開「惡意手法」，四個步驟和示意圖也要夠用

### 示意圖

每一步一張：淺灰（`--soft`）底的圓角面板，左上一行次要色的小字標題，寫明「示意」。

- 只用墨、正文、次要、線、淺灰（`design/DESIGN.md`「顏色」）：不用綠、不打勾、覆盆子紅不當警告；事實頁不用點
- 用 HTML 和 `pages.css` 的 class 畫，沒有圖片檔、沒有行內樣式
- 圖裡的元素對螢幕報讀器隱藏；每張圖另有一段只給螢幕報讀器的說明（看不到）。圖的標題和圖下面的那一句照常讀出來
- 個人檔案的卡片是一般的樣子，不照抄 Threads 的介面

每一步的第一個程式碼區塊是左邊的字；第二個是示意圖上的字，由上到下；第三個是給螢幕報讀器的說明。

### 第 1 步

```
1 在個人檔案上找連結
打開那個帳號在 Threads 的個人檔案，找 iamreal.tw/p/ 開頭的連結，例如 iamreal.tw/p/7K2Q9FM4XD。帳號主人自己把這個連結掛上個人檔案，才代表他承認這張證明。
惡意手法
在貼文、留言或私訊裡貼出島民證明的截圖或連結，宣稱自己有台灣人背書。截圖可以造假，連結也可能是別人的；任何一張卡片都能宣告任何帳號。只有帳號主人掛在自己個人檔案上的連結才算數。
```

```
Threads 的個人檔案（示意）
Alice
@alice
iamreal.tw/p/7K2Q9FM4XD
找這個連結
1,204 位粉絲
```

```
一個帳號的個人檔案：名稱 Alice、帳號 @alice，簡介下面有一行連結 iamreal.tw/p/7K2Q9FM4XD，要找的就是這個連結。
```

白底細框的卡片：名稱、帳號在左，右邊灰色圓形的大頭貼；下面兩條灰色的簡介。連結那一行（連結圖示加粗體的網址，Threads 上的連結是粗體）用 2px 墨色框框起來，下面一個墨底白字的標籤「找這個連結」；卡片最下面是粉絲數。

### 第 2 步

```
2 點開，看網址列
網域要一字不差是 iamreal.tw。像 iamreal.tw.○○○.com、iamreal-tw.○○○ 這樣前後多了字的，都不是島民證明的網站，不要在那裡輸入任何資料。
惡意手法
做一個和島民證明長得一模一樣的假網站，網域只差幾個字，在上面寫著這個帳號有島民證明。畫面可以照抄，網域抄不了。
```

```
點開之後的網址列（示意）
是
iamreal.tw/p/7K2Q9FM4XD
島民證明的網站
下面這些都不是：
✕ 不是
iamreal.tw.○○○.com/p/7K2Q9FM4XD
iamreal.tw 後面多了字
✕ 不是
iamreal-tw.○○○/p/7K2Q9FM4XD
網域不一樣
```

```
三個網址。iamreal.tw/p/7K2Q9FM4XD 是島民證明的網站。iamreal.tw.○○○.com/p/7K2Q9FM4XD 在 iamreal.tw 後面多了字，iamreal-tw.○○○/p/7K2Q9FM4XD 的網域不一樣，這兩個都不是。
```

三條圓角的網址列，左邊各一個標籤。

- 第一條：墨底白字的「是」，網址列 2px 墨框，網域（`iamreal.tw`）粗體，下面「島民證明的網站」
- 之後一條細線和「下面這些都不是：」
- 兩條錯的：白底墨框的「✕ 不是」，網址用次要色，多出來的字反白（墨底白字）：第一條是 `.○○○.com`，第二條是 `-` 和 `.○○○`

### 第 3 步

```
3 比對帳號名稱
頁面上最大的字是這張島民證明給的帳號，要和你剛才看的帳號一字不差，句點和底線也算。
惡意手法
把別人的島民證明連結掛到自己的個人檔案上，或取一個很像的帳號名稱，例如用 @alice_ 冒充 @alice。島民證明頁上寫的帳號和你看的不一樣，就不算。
```

```
兩邊對照（示意）
Threads 的個人檔案
Alice
@alice
iamreal.tw/p/7K2Q9FM4XD
1,204 位粉絲
＝
島民證明的頁面
第 1,284 張島民證明
一張台灣國民的自然人憑證，
把它在 Threads 唯一的名額給了
@alice
@alice、@alice_、@alice.tw 是三個不同的帳號，要一字不差。
```

```
左邊是 Threads 的個人檔案，帳號 @alice；右邊是島民證明的頁面，第 1,284 張島民證明，最大的字也是 @alice。
```

- 左邊是小一號的個人檔案卡片，和第 1 步的同樣子；@alice 粗體加粗底線，連結照樣是粗體、不框，沒有「找這個連結」
- 中間一個明體的「＝」
- 右邊是島民證明的頁面：次要色小字的張數、明體兩行標題（`proof-page.md` 第 1 段）、大字的 @alice（加粗底線）
- 桌機左右並排，手機上下排
- 最後一句在圖的下面，是面板裡的一般文字，螢幕報讀器照常讀

### 第 4 步

```
4 看上次過卡是幾天前
過卡那一天，這張自然人憑證在效期內、不在廢止清冊上。之後卡片還有沒有效，要等下一次過卡才知道。所以越久沒過卡，這張證明的說服力越低；我們建議持卡人每三個月過卡一次。
惡意手法
用一張卡替一個帳號換島民證明，接著掛失這張卡、補辦新卡，再替下一個帳號換一張，一個人就能替好幾個帳號背書。掛失的卡不能再過卡，舊帳號的證明停在掛失之前，天數只會越來越大。
```

```
島民證明頁上的「上次過卡」（示意）
上次過卡：12 天前（2026-11-13）
上次過卡：400 天前（2025-10-21）
兩張證明的寫法相同，差別只在天數。天數越大，這張證明的說服力越低：卡片可能已經掛失或過期，再也沒辦法過卡，上次過卡的日期就停在那一天。
```

```
兩行同樣式的字：上次過卡：12 天前（2026-11-13）；上次過卡：400 天前（2025-10-21）。
```

- 兩行的樣式照島民證明頁第 2 段的第一行（`proof-page.md`）：括號裡的日期小一號、淡色；兩行樣式相同，不加警告
- 最後一句在圖的下面（兩行的下面），是面板裡的一般文字，螢幕報讀器照常讀

## 3. 島民證明告訴你什麼

```
島民證明告訴你什麼

告訴你的
有一張台灣國民的自然人憑證，把它在 Threads 唯一的名額給了這個帳號，以及上次過卡是哪一天。

不會告訴你的
卡片是誰的，以及過卡的人是不是自然人憑證上的那個人：卡片可能遺失，也可能被借走或賣給別人。

一張卡片，一個帳號
一張自然人憑證在 Threads 同一時間只能把名額給一個帳號。要有一萬個有島民證明的帳號，得先有一萬張真的卡片。
```

第一行是小標。下面三塊，每一塊第一行是小標，第二行是說明；桌機三欄，手機上下排。

## 4. 常見的狀況

```
常見的狀況

個人檔案上沒有連結
可以到證明紀錄查這個帳號，看有沒有自然人憑證把名額給了它。查得到也不代表帳號主人承認：任何一張卡片都能宣告任何帳號，帳號主人把連結掛上個人檔案，才看得出他承認。

點開的頁面寫的是別的帳號
這個連結不是這個帳號的島民證明，不能拿來當作這個帳號的背書。可能是有人故意掛上別人的島民證明，假裝有台灣人背書；也可能是帳號改了名稱、還沒回來更換，或持卡人已經把名額換給了別的帳號。

頁面說「找不到這張島民證明」
這個網址沒有對到任何一張自然人憑證。如果你是從某個帳號的個人檔案點進去的，那個帳號掛的島民證明並不存在。可能是有人故意掛上不存在的連結，假裝有台灣人背書；也可能是連結抄錯了。

想自己驗證每一張島民證明
每一張島民證明都附著一份零知識證明，公布在證明紀錄裡，任何人都能用公開的程式重算。做法在如何驗證證明紀錄。
```

第一行是小標。每一種狀況第一行是小標，第二行是說明。

- 「個人檔案上沒有連結」的「證明紀錄」是連結，連到證明紀錄頁的查詢那一欄（`/proof-log#q`）
- 最後一條的「如何驗證證明紀錄」是連結，連到 `/verify`（`verify.md`）；同一句的「證明紀錄」不是連結

最後一段下面不另外放東西，直接接頁尾（`home.md`「頁尾」）。
