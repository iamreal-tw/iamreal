# 查詢頁

`iamreal.tw/threads/@alice`。回答「有沒有自然人憑證把名額給了 @alice」：列出現在把 Threads 的名額給了這個帳號的卡片，每一張連到它的島民證明。它不是任何人的島民證明。原則在 `docs/design/principles.md` 的「查詢頁」。

- 張數不放大
- 不合併日期：每一張的日期只屬於那一張，沒有整個帳號的「最近一次過卡」（`principles.md`「查詢頁」）
- 不替訪客標出帳號主人認的是哪一張（ADR-0003）
- 只有一張時，也不自動跳到那一張島民證明：這一頁是查詢的結果，島民證明的頁面才是證明
- 稱呼用「你」

例子裡的 `@alice`、`Threads`、`7K2Q9FM4XD`、`3M8T1RZ6WA`、日期、天數、張數是會換掉的值，其餘是固定的文字。「看這張島民證明」是連結。

## 1. 有一張

```
Threads 的 @alice

有 1 張自然人憑證把它在 Threads 的名額給了這個帳號。

島民編號 7K2Q9FM4XD 開頭　　2026-03-02 起　　上次過卡 12 天前　　看這張島民證明

帳號主人承認的是哪一張，看 @alice 的個人檔案上放的是哪一張的連結：

（Threads 的個人檔案嵌入）

任何持卡人都可以把名額給任何帳號，張數不代表支持或連署。
```

- 每一張一列：島民編號的開頭、從哪一天起、上次過卡幾天前，和連到它的島民證明（`iamreal.tw/p/7K2Q9FM4XD`）的「看這張島民證明」
- 「從哪一天起」是這張卡片開始把名額給這個帳號的那一筆紀錄的日期：新宣告、更換、更正，或收回之後的再次宣告。再次過卡不會改它
- 個人檔案只嵌入一次，放在清單下面。個人檔案上的連結結尾就是島民編號的開頭，訪客拿它和每一列比對
- 最後一句固定顯示

## 2. 有好幾張

和「有一張」相同，張數換掉，每一張一列：

```
Threads 的 @alice

有 2 張自然人憑證把它在 Threads 的名額給了這個帳號。

島民編號 7K2Q9FM4XD 開頭　　2026-03-02 起　　上次過卡 12 天前　　看這張島民證明
島民編號 3M8T1RZ6WA 開頭　　2026-05-10 起　　上次過卡 3 天前　　看這張島民證明

帳號主人承認的是哪一張，看 @alice 的個人檔案上放的是哪一張的連結：

（Threads 的個人檔案嵌入）

任何持卡人都可以把名額給任何帳號，張數不代表支持或連署。
```

- 照「從哪一天起」排，早的在前。不照上次過卡排：那樣頻繁過卡的卡片就能一直排在最上面
- 只列現在還把名額給這個帳號的卡片。以前給過、後來更換或收回的，在各自島民證明的「全部紀錄」裡
- 兩張以上的島民編號開頭 10 個字元相同時，照 `GLOSSARY.md`「島民編號」寫到分得開為止

## 3. 一張都沒有

```
Threads 的 @alice

沒有自然人憑證把名額給這個帳號。
名稱要和 Threads 上的完全相同。
```

只寫事實，不寫解讀。不嵌入個人檔案：沒有任何一張島民證明可以拿來比對。
