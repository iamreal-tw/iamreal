# 查詢頁

`iamreal.tw/threads/@alice`。回答「有沒有自然人憑證宣告了 @alice」：列出現在把 Threads 的名額給了這個帳號的卡片，每一張連到它的島民證明。它不是任何人的島民證明。原則在 `docs/design/principles.md` 的「查詢頁」。

- 張數不放大
- 不合併日期：每一張的日期只屬於那一張，沒有整個帳號的「最近一次過卡」（`principles.md`「查詢頁」）
- 不替訪客標出帳號主人認的是哪一張（ADR-0003）
- 只有一張時，也不自動跳到那一張島民證明：這一頁是查詢的結果，島民證明的頁面才是證明
- 稱呼用「你」

例子裡的 `@alice`、`Threads`、`7K2Q9FM4XD`、`3M8T1RZ6WA`、日期、天數、張數是會換掉的值，其餘是固定的文字。「看這張島民證明」「個人檔案」是連結。

帳號名稱單獨一行，和島民證明頁的帳號一樣大（`proof-page.md` 第 1 段）；「Threads 的」在它上面，小一號。排法和島民證明頁相同：手機上由上到下是帳號和張數、個人檔案、每一張一列的清單；桌機上左欄是帳號、張數和個人檔案，右欄是清單，和左欄同一個高度開始。清單會隨卡片變長，放在後面（桌機的右欄），不會把個人檔案推下去。一張都沒有時只有帳號和下面兩行。

## 1. 有一張

```
Threads 的 @alice
有 1 張自然人憑證宣告了這個帳號。
任何持卡人都可以宣告任何帳號，張數不代表支持或連署。

個人檔案上有哪一張的連結，才代表 @alice 承認那一張。

（Threads 的個人檔案嵌入）

島民編號 7K2Q9FM4XD 開頭　　看這張島民證明
2026-08-01 起　　上次過卡 12 天前
```

- 每一張一列：島民編號的開頭，緊接著連到它的島民證明（`iamreal.tw/p/7K2Q9FM4XD`）的「看這張島民證明」；下面一行是從哪一天起、上次過卡幾天前
- 天數一律用天，照台灣的日期算。上次過卡日就是今天時寫：

```
上次過卡 今天
```

- 「從哪一天起」是這張卡片開始把名額給這個帳號的那一筆紀錄的日期：新宣告、更換，或收回之後的再次宣告。再次過卡不會改它
- 張數那一行和帳號同一段，不放大；下面那一句是小字，固定顯示，緊接在張數後面（`principles.md`「查詢頁」：張數旁邊固定有這一句）
- 「個人檔案上有哪一張的連結，才代表 @alice 承認那一張。」是小標，寫法和島民證明頁第 2 段的小標相同：一行放不下時斷在逗號或空格，「個人檔案」是連到 `https://www.threads.com/@alice` 的連結，嵌入框顯示不出來時從這裡到 Threads 上看。個人檔案只嵌入一次，放在它下面，下面不放句子。個人檔案上的連結結尾就是島民編號的開頭，訪客拿它和每一列比對

## 2. 有好幾張

和「有一張」相同，張數換掉，每一張一列：

```
Threads 的 @alice
有 2 張自然人憑證宣告了這個帳號。
任何持卡人都可以宣告任何帳號，張數不代表支持或連署。

個人檔案上有哪一張的連結，才代表 @alice 承認那一張。

（Threads 的個人檔案嵌入）

島民編號 7K2Q9FM4XD 開頭　　看這張島民證明
2026-08-01 起　　上次過卡 12 天前
島民編號 3M8T1RZ6WA 開頭　　看這張島民證明
2026-09-01 起　　上次過卡 3 天前
```

- 照「從哪一天起」排，早的在前。不照上次過卡排：那樣頻繁過卡的卡片就能一直排在最上面
- 只列現在還把名額給這個帳號的卡片。以前給過、後來更換或收回的，在各自島民證明的證明紀錄裡
- 兩張以上的島民編號開頭 10 個字元相同時，照 `GLOSSARY.md`「島民編號」寫到分得開為止

## 3. 一張都沒有

```
Threads 的 @alice

沒有自然人憑證宣告這個帳號。
名稱要和 Threads 上的完全相同。
```

只寫事實，不寫解讀。不嵌入個人檔案：沒有任何一張島民證明可以拿來比對。

## 4. 名稱不合 Threads 的格式

網址裡的名稱不可能是 Threads 的帳號名稱時（例如有 `-`、空白、超過 30 個字元），不是上面三種情況，是另一頁，狀態碼 404：

```
Threads 沒有這樣的帳號名稱

Threads 的帳號名稱只有英文字母、數字、句點和底線。

查一個 Threads 帳號
```

「查一個 Threads 帳號」是連結，連到證明紀錄頁（`proof-log-page.md`），停在查詢的那一欄。不嵌入個人檔案。

## 5. 連結被貼出去時的預覽

```
標題：Threads 的 @alice
網站：島民證明 iamreal.tw
```

- 不寫摘要；圖是每一頁同一張（`proof-page.md`「預覽圖」）
- 分頁的標題是預覽的標題後面加「｜島民證明」：`Threads 的 @alice｜島民證明`
