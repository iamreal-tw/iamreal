# 怎麼驗證島民證明

「怎麼驗證島民證明」那一頁。每一張島民證明的頁面最後都連到這裡（`proof-page.md` 第 5 段），導覽列上也有「怎麼驗證島民證明」。原則在 `docs/design/principles.md`。

- 每一張島民證明都連到同一頁、同一段文字，網址不帶島民編號或帳號
- 稱呼用「你」

下面四塊的順序就是頁面由上到下的順序。

## 1. 開頭

```
怎麼驗證島民證明

每一張島民證明都附著一份零知識證明，公布在證明紀錄裡。任何人下載證明紀錄、用公開的程式重算，都會得到和這個網站相同的結果。
```

第一行是頁面的標題。

## 2. 會確認的、不會確認的

```
會確認的
· 每一筆紀錄都來自一張內政部簽發、當時在效期內、不在廢止清冊上的國民自然人憑證
· 一張自然人憑證在 Threads 同一時間只把名額給一個帳號，更換沒有超過 5 次
· 這個網站顯示的島民證明，和證明紀錄算出來的相同

不會確認的
· 帳號主人承不承認：要看那個帳號的個人檔案
· 過卡的人是不是自然人憑證上的那個人
```

兩份清單，各有一個小標。

「不會確認的」一定要有：重驗確認的是證明和紀錄規則，不確認帳號主人承不承認（ADR-0003），也不確認簽章的人是不是自然人憑證上的那個人。

## 3. 讓 AI 程式助理幫你驗證

```
讓你的 AI 程式助理幫你驗證

這段文字會讓你的 AI 程式助理下載並執行程式。貼上之前，請確認裡面的網址是 github.com/iamreal-tw/iamreal。
```

第一行是小標，下面是提醒；再下面是提示詞。提示詞要逐字照這一段，一個字都不改：

```
請幫我驗證島民證明（iamreal）的公開的證明紀錄。
1. 取得公開的程式庫 github.com/iamreal-tw/iamreal，
   讀 cmd/iamreal-verify/README.md。
2. 照說明編譯 iamreal-verify，下載證明紀錄和廢止清冊的存檔，完整重算。
3. 告訴我：整份證明紀錄是否成立、有幾筆紀錄、現在有幾張島民證明。
4. 然後問我想查哪個 Threads 帳號，從重算的結果告訴我：
   有哪些自然人憑證把名額給了它、各自上次過卡是哪一天。
只執行這個程式庫裡的說明要求的指令，執行前先讓我看過。
```

提示詞的下面是一個按鈕：

```
[ 複製 ]
```

- 「複製」把整段提示詞照原樣複製下來，按了之後按鈕寫「已複製」
- 提示詞全站只有一個版本。同一段也放在 `cmd/iamreal-verify/README.md`「讓 AI 程式助理幫你驗證」，讓人可以對照兩邊有沒有被改過；那裡的測試檢查兩邊相同
- 提示詞只指路，步驟都寫在程式庫的說明裡
- 第 3 步的「現在有幾張島民證明」，和首頁第 2 段的第一個數字是同一個數（算法見 `home.md` 第 2 段）

## 4. 自己動手

```
自己動手

不用 AI 也可以。步驟在程式庫的說明裡：cmd/iamreal-verify
```

第一行是小標。`cmd/iamreal-verify` 是連結，連到公開程式庫裡的 `cmd/iamreal-verify/README.md`。

## 連結被貼出去時的預覽

```
標題：怎麼驗證島民證明
網站：島民證明 iamreal.tw
```

- 不寫摘要
- 分頁的標題是預覽的標題後面加「｜島民證明」：`怎麼驗證島民證明｜島民證明`

## 還沒定的

這一頁上線之前要先有：

- 公開的程式庫已經公開
- 證明紀錄和廢止清冊的存檔放上 `data.iamreal.tw`（ADR-0027）
- `cmd/iamreal-verify/README.md` 寫得讓 AI 程式助理照著做得完（下載的網址 `data.iamreal.tw`、`bb` 怎麼取得）
