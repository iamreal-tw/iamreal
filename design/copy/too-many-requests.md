# 請求太多的頁面

同一個網路在一分鐘內要了太多頁面時，後台不再回答頁面，改回這一頁，狀態碼 `429`，附 `Retry-After: 60`（ADR-0026）。正式網站和測試網站都用這一頁；測試網站上，最上面照樣有測試的證明紀錄的標示（`test-site.md`）。原則在 `docs/design/principles.md`。

過卡的介面被擋下時不是這一頁：介面回的是代碼，畫面上的句子在 `card-proof.md`。

## 頁面

```
請稍後再試

這個網路送出的請求太多，請過一分鐘再試。
```

- 第一行是標題，也是分頁的標題（`請稍後再試｜島民證明`）；沒有連結預覽
- 只講「這個網路」，不寫位址，也不寫是哪一個上限、算到幾次
- 沒有「回到首頁」：首頁也是頁面，一分鐘內同樣要不到
- 導覽列和頁尾和其他頁面相同

## 人太多的時候

不是同一個網路要太多，是全站一起來的人太多：後台的證明紀錄應付不了這麼多請求時，要讀它的頁面（首頁、島民證明、查詢頁、證明紀錄頁、掛上去）改回這一頁，狀態碼 `503`，附 `Retry-After: 60`（ADR-0026：Durable Object 回 `overloaded` 時）。

```
現在人太多

現在使用島民證明的人太多，請過一分鐘再試。
```

- 第一行是標題，也是分頁的標題（`現在人太多｜島民證明`）；沒有連結預覽
- 不講是誰送了太多：不是這個網路的問題
- 其餘和上面那一頁相同：導覽列和頁尾照常，沒有「回到首頁」
