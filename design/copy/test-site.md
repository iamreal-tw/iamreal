# 測試網站

`test.iamreal.tw`，放測試的證明紀錄的網站（ADR-0028）。它的頁面和正式網站用同一份文字，只多這一份寫的東西。原則在 `docs/design/principles.md`。

例子裡的 `2026-11-20` 是會換掉的值，其餘是固定的文字。

## 測試的證明紀錄的標示

測試網站的每一頁最上面，導覽列之前。找不到的頁面（`404`）也有。

```
測試的證明紀錄　不定期清空，上次清空：2026-11-20
```

- 「測試的證明紀錄」和後面的句子之間是一個全形空格
- 日期是測試環境設定裡的上次清空日期。還沒清空過時，是測試網站第一次部署的日期
- 寫「不定期清空」，訪客才知道現在打得開的連結之後可能失效；用詞和 `privacy.md` 相同
- 清空之後連到「找不到」的連結，靠這個日期說明原因，所以找不到的頁面也要有這一行
- 正式的網站沒有這一行

這一句是營運者定的（[#59](https://github.com/iamreal-tw/iamreal/issues/59)）。

## 寫出島民證明網址的地方

有三個地方寫出一張島民證明的網址：島民證明自己（個人檔案上要有的連結，和短編號對不到任何卡片時的那一句；`proof-page.md` 第 3、9 段）、過卡的完成畫面（畫面上的連結和「複製連結」複製的字；`card-proof.md` 第 6 步）、掛上去那一頁（`hang.md` 第 2 部分）。測試網站上，這些地方都寫測試網站的網域：

```
test.iamreal.tw/p/7K2Q9FM4XD
```

- 持卡人照這一行放到個人檔案上，連到的才是測試的證明紀錄裡的這一張島民證明
- 其餘的文字和各頁自己的那一份相同
- 導覽列、頁尾、分頁標題、連結預覽的網站名稱裡的 `iamreal.tw` 是島民的名字，測試網站上不變
