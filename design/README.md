# design

各平台共用的介面文字和設計語彙。

## 讓人檢查什麼

網頁、Android、iOS 對持卡人和訪客說的是同一句話。畫面上每一句給人看的話都從這裡來，各平台不各寫一份。

## 內容

| 路徑 | 內容 |
|---|---|
| `copy/` | 畫面上的文字，一個流程一份 |
| `tokens.json` | 顏色、字級、間距（還沒有定） |

原則在 `docs/design/principles.md`，用詞以根目錄的 `GLOSSARY.md` 為準。改這裡的文字之前先讀那兩份。

## 怎麼單獨使用

這個目錄只有文字檔，不引用其他目錄，沒有要執行的程式。
