# 名冊只記持卡人的宣告，不確認帳號主人是否承認

名冊記的是一件事：某張卡片在某一天把名額宣告給了某個帳號。帳號主人承不承認，後台不檢查、不記錄、不擔保。任何持卡人都可以宣告任何帳號，包括別人的。帳號主人要表示承認，就把徽章頁的連結放在自己的貼文或個人檔案上（連回），由訪客自己看兩邊對不對得上。

理由：

- **要後台確認，就得讓帳號主人用平台帳號登入並授權。** 那樣每一筆「帳號主人承認」都是只有營運者看得到的紀錄，外人無法重驗；專案也會依賴平台的 API、審查和條款，平台一改就停擺。
- **只有持卡人這一半，仍然有價值。** 稀缺的是名額：要讓一萬個帳號有宣告，需要一萬張真的卡片，每張都放棄自己在這個場合唯一的名額，不論那些帳號同不同意。
- **連回是公開的，任何人都能自己確認。** 從 @alice 的個人檔案點進來，徽章頁寫的是 @alice，就對上了；寫的是別人，就是在借別人的徽章。

## Considered Options

- **帳號主人用平台帳號登入，後台確認後才寫入名冊**：見上面第一點。
- **帳號主人發一則含指定字串的貼文，後台去讀**：後台同樣要透過平台讀取內容，而且貼文會被洗掉或刪除。

## Consequences

- 名冊上的每一筆都附證明，沒有「營運者說某天看過」這種要人相信的紀錄。
- 對外不說「已驗證」「這個帳號是真人」。完整的說法是「有自然人憑證持卡人宣告」。
- 一個帳號可以被多張卡片宣告，帳號主人拿不掉別人的宣告。不想認的就不連回，或只連回指定的那一筆。筆數不代表支持或連署，徽章頁要寫明。
- 「帳號主人承不承認」機器查不到。API 只能回答「有沒有卡片宣告這個帳號」，查詢方要自己決定這夠不夠。
