# 場合代號和證明公開在名冊上

名冊上每一筆事件都公開它的場合代號、三份證明和公開輸入。任何人不經過營運者，就能重驗每一筆。

理由：

- **「任何人都能重驗」是這個專案的核心承諾。** 不公開，大家就得相信營運者說的「這筆我驗過了」。
- **場合代號本來就是證明的公開輸出。** 電路是這樣設計的（ADR-0001），要讓人重驗證明，就一定看得到場合代號。
- **營運者手上沒有祕密。** 被入侵或被要求交出資料時，交得出去的都是本來就公開的東西。

## Considered Options

- **不公開，由營運者驗證，再請獨立稽核者複查**：大眾要相信營運者和稽核者。
- **持卡人自備一個祕密，混進場合代號**：只能做到混在同一批人裡，複雜度不值得。
- **不用零知識證明，名冊直接記卡號**：憑證上有姓名，拿著「姓名對應卡號」清單的人可以直接對出本人。沒有中間選項。

## Consequences

- **公開之後收不回來。** 先匿名，之後可以讓人自願公開；反過來做不到。
- **能讓卡片簽章一次的人，查得出這張卡片宣告了哪個帳號。** 他讓卡片簽場合文字，算出場合代號，再對照名冊。家人、代辦的人、假網站、惡意程式都可能做到，發生在宣告之前或之後都一樣。帳號有連回時等於被確認；沒有連回時只能猜，但小帳號很容易被猜中。這個風險要在持卡人過卡之前用白話講清楚，由他自己決定。
- 對外承諾的精確說法是：「平台、營運者、政府，都查不出你是誰。但一旦你的自然人憑證交給別人使用，對方就能查出它宣告了哪個社群帳號。」
- API 的 `scoped_id` 欄位是不透明的識別碼，查詢方不應假設它的格式。
