# 匿名編號和證明公開在證明紀錄裡

證明紀錄裡每一筆事件都公開它的匿名編號、證明和公開輸入（每次過卡一份證明，ADR-0013）。任何人不經過營運者，就能重驗每一筆。

理由：

- **「任何人都能重驗」是這個專案的核心承諾。** 不公開，大家就得相信營運者說的「這筆我驗過了」。
- **匿名編號本來就是證明的公開輸出。** 要讓人重驗證明，就一定看得到匿名編號。
- **營運者手上沒有姓名、身分證字號和憑證。** 被入侵或被要求交出資料時，交得出去的是本來就公開的東西，加上最近 31 天的連線紀錄（ADR-0022）。

## Considered Options

- **不公開，由營運者驗證，再請獨立稽核者複查**：大眾要相信營運者和稽核者。
- **持卡人自備一個祕密，混進匿名編號**：只能做到混在同一批人裡，複雜度不值得。
- **不用零知識證明，證明紀錄直接記卡號**：憑證上有姓名，拿著「姓名對應卡號」清單的人可以直接對出本人。沒有中間選項。

## Consequences

- **公開之後收不回來。** 先匿名，之後可以讓人自願公開；反過來做不到。
- **能讓卡片簽章一次的人，查得出這張卡片在公開的證明紀錄裡宣告了哪些帳號**（所有公開平台共用一個匿名編號，ADR-0017）。 他讓卡片簽場合字串，算出匿名編號，再對照證明紀錄。家人、代辦的人、假網站、惡意程式都可能做到，任何能要求卡片簽它指定內容的網站也做得到，包括用自然人憑證登入的政府網站；發生在宣告之前或之後都一樣。帳號有連回時等於被確認；沒有連回時只能猜，但小帳號很容易被猜中。這個風險要在持卡人過卡之前用白話講清楚，由他自己決定。
- **場合字串的簽章外流之後，沒有辦法讓它失效，直到換一張新卡。**
- 對外承諾的精確說法是：「證明紀錄裡的紀錄查不出你是誰。你過卡時的連線 IP，營運者和 Cloudflare 會留 31 天；這段期間內，營運者或依法調閱的機關，可以經電信業者查到這筆紀錄是從哪條線路送出的。沒有成功的請求，內容也會留 31 天，用來查錯。一旦你的自然人憑證交給別人使用，對方就能查出它宣告了哪些社群帳號。」（連線紀錄的部分見 ADR-0022）
- 網頁版的簽章經過內政部的元件，和其他使用自然人憑證的網站相同。元件看得到場合字串和簽章。
- **匿名編號只有持卡人算得出來，前提是卡片的金鑰分解不了。** 分解得了的話，拿到公鑰的人就能自己簽場合字串。2013 年有研究者分解了 184 把台灣自然人憑證的 1024 位元金鑰（[Factoring RSA keys from certified smart cards: Coppersmith in the wild](https://smartfacts.cr.yp.to/)，ASIACRYPT 2013）。現在的卡片是 2048 位元，我們不知道有沒有人公開檢查過。
- **匿名的期限是卡片金鑰的壽命。** 證明紀錄永久公開；卡片的 RSA 金鑰將來如果能被破解，拿得到那張憑證公鑰的人，可以算出它的匿名編號，把已經公開的紀錄對回憑證。換算法也避免不了，因為紀錄已經公開。
- **每一筆事件看得出憑證是哪一把發證金鑰簽的。** 證明的公開輸入包含發證金鑰（ADR-0013）。內政部目前有兩把，分別從 2014 年和 2024 年開始使用，所以看得出這張憑證大約是哪一段時間發的或展期的。第三代啟用以後辦的展期一律由第三代簽（內政部憑證管理中心回覆我們的詢問），所以一張第二代簽發的卡片，展期前後各過卡一次，證明紀錄裡同一個匿名編號的發證金鑰會換代，看得出它在這兩次過卡之間展期過。內政部知道誰在什麼時候展期。電路不為此改：要把兩把發證金鑰藏進同一份電路，電路會超過目前的大小上限。
- API 的 `scoped_id` 欄位是不透明的識別碼，查詢方不應假設它的格式。
