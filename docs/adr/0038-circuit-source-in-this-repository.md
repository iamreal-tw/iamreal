# 電路的原始碼放在這個程式庫的 `circuits/`，不帶先前的歷史；CI 只在改到電路的 PR 上重建並比對

電路的 Noir 原始碼、電路的測試、逐案比對和隨機差異測試的程式放在這個程式庫的 `circuits/`。它們原本在一個私有的程式庫，從那裡的提交 `497b610c64a3e598ccc769f39e886d1d5ca889ed` 搬過來，不帶歷史。`circuits/` 有一個重建並比對的指令：用釘住的 `nargo`、`bb` 從原始碼重編兩份電路，和 `web/circuits/`、`verifier/vk/` 逐位元組比對。CI 照 `checks-browser.yml` 的先例，只在 PR 改到電路的輸入時跑這個指令和電路的測試，不是必要檢查，不在合併佇列裡跑。討論在 [#201](https://github.com/iamreal-tw/iamreal/issues/201)，規格在 [#243](https://github.com/iamreal-tw/iamreal/issues/243)。

## 放在這裡

- **電路是這個程式庫要讓人檢查的一件事。** 卡片的哪些東西會被檢查、匿名編號怎麼算，都寫在電路裡。之前任何人只能核對「從電路檔寫出的驗證金鑰和後台用的相同」，不能核對電路檔是從哪份原始碼編出來的、電路檢查了什麼。最上層的目錄照「公開這段程式，是為了讓人能檢查哪一件事」來分（`CLAUDE.md`），電路剛好是其中一件。
- **改電路是一個 PR。** 原始碼、編好的電路檔、驗證金鑰、規格和標準答案在同一個程式庫，一起改、一起審；不用在兩個程式庫之間靠人同步釘住的提交。
- **電路的測試讀 `spec/vectors/` 的同一份標準答案**，和 Go、TypeScript、Rust 的實作相同。Poseidon2 的標準答案原本在兩個程式庫各有一份，現在只剩 `spec/vectors/poseidon2.json`。

## 不帶歷史

- 先前的程式庫裡有 AI 檢查的原始紀錄，含用完即丟的私鑰和見證檔。這些只公開整理過的摘要（`circuits/REVIEW.md`），原始紀錄不公開；檢查用的程式（隨機差異測試）照樣搬過來。帶歷史就會把原始紀錄一起帶進來。
- 主幹的歷史掃過一遍，沒有真卡資料、身分證字號。本機路徑和先前程式庫的名字出現在 AI 檢查的原始紀錄（`audit/`）和舊版的 README 裡；這兩樣都沒有搬進來，不帶歷史也就不會把它們帶進來。
- 搬檔的兩個提交裡，每個檔都和 `497b610` 的對應檔逐位元組相同（第一個是電路、測試和逐案比對，第二個是隨機差異測試的程式和兩張結果表）；改寫和整理放在後面的提交，讓人比得出搬的時候沒有偷改。寫著原本那台電腦上的目錄配置（例如 `~/Workspace/zkID`）的四個檔（兩份 README、隨機差異測試的兩個檔）不放進這兩個提交，改過才放進來，`circuits/README.md` 寫了是哪幾個。

## CI 照 `checks-browser.yml` 的先例

- 電路很少改，大部分的 PR 不會跑它；含 circom 的逐案比對要先建 circom 的見證產生器，比其他檢查慢。
- 不是必要檢查，也不在合併佇列裡跑，佇列不會因為一個很少相關的慢檢查變慢；和 #206「合併佇列裡必要檢查全部都跑」的規則不衝突。
- 它在 PR 上出現時要通過，agent 才能把 PR 排進合併佇列，和 `browser`、`ios` 一樣。

## Considered Options

- **把先前的程式庫轉公開，這裡用提交釘住它**：保留獨立的程式庫和歷史。代價是標準答案要跨庫共用，改電路要兩個 PR，釘住的提交要靠人同步。
- **帶歷史搬進來**：看得到電路怎麼一步步改成現在這樣，但原始的 AI 檢查紀錄會跟著公開。
- **電路的檢查放進 `checks.yml`，每個 PR 都跑**：不會漏，但每個 PR 都要裝 Noir 的工具鏈、建 circom；放進必要檢查也會讓合併佇列變慢。

## Consequences

- **電路的檢查漏列一個檔，會有該跑卻沒跑的 PR。** `worker/test/workflows.test.ts` 從測試的原始碼讀出它們用到的檔，檢查都在 `paths` 裡（[#247](https://github.com/iamreal-tw/iamreal/issues/247)）。
- **換 `nargo` 或 `bb` 的版本，重建並比對的指令會說出電路檔和驗證金鑰有沒有變。** 變了就是名額重來（ADR-0012），要另外討論。
- **先前的私有程式庫在 `circuits/` 合併、電路的檢查在 PR 上通過之後封存。** 測試資料產生器和文件改指 `circuits/`（[#246](https://github.com/iamreal-tw/iamreal/issues/246)）。
- **`circuits/` 的授權是這個程式庫的 Apache-2.0。** 照 PSE zkID（MIT）測試案例重寫的測試，檔頭和 `circuits/README.md` 註明出處和授權；引用的 Noir 函式庫的授權列在 `circuits/README.md`。
