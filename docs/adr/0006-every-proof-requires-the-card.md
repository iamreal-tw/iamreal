# 每次證明都要卡片在場

證明紀錄裡的每一筆事件，都要持卡人當下拿出卡片、輸入 PIN、讓卡片簽章才能產生。我們不做任何「過卡一次，之後不用卡片」的機制。具體來說有兩個不做：

- **通行證**：過卡一次後，在裝置上留下一份可以重複使用的憑據，之後用它產生證明。
- **保活證明**：不插卡、不輸入 PIN，只重新證明憑證還沒被廢止，用來更新日期。

理由：

- **可以離開卡片的東西，就可以被複製和轉手。** 被收買的持卡人把裝置裡的資料交出去，對方就能一直用，等於一次買斷。卡片的私鑰拿不出來，所以要求卡片在場時，每一次都要持卡人本人配合。
- **通行證出事時，是一批人同時被冒用。** 這會直接傷到這個專案唯一值錢的東西，也就是大家對證明紀錄的信任。
- **保活證明會讓證明紀錄多一個比較弱的日期。** 兩個日期並列，弱的那個很容易被當成和上次過卡日一樣可靠。它還要把憑證（含姓名）留在瀏覽器裡。

## Consequences

- 證明紀錄裡只有一種新鮮度的日期：上次過卡日。它的意思很單純：那一天，卡片在持卡人手上，憑證沒有被廢止。
- 持卡人要定期拿卡片出來過卡，日期才不會變舊。這是成本，所以過卡的流程要盡量輕鬆；手機用 NFC 讀卡是預計的解法。
- 每個場合都要各自過卡，沒有「過一次卡，到處可用」。公開的證明紀錄是一個場合：過一次卡，這張卡片宣告的所有帳號一起更新（ADR-0017）；其他服務的場合各自過卡。
