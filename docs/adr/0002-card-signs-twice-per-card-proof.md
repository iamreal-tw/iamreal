# 每次過卡，卡片簽兩次

每次過卡，卡片簽兩段字：先簽場合文字，再簽宣告碼。瀏覽器算三份證明：憑證證明、場合簽章證明、宣告碼簽章證明。三份帶著同一個公鑰承諾值，後台據此確認它們來自同一張卡片。電路沒有修改（ADR-0001），只是把簽章的那一種電路跑兩次。

兩次簽章各有用途：

- **第一次（場合文字）產生場合代號。** 場合文字是固定的，同一張卡片每次簽出來都一樣，所以場合代號不變，一張卡片在一個場合只有一個名額。
- **第二次（宣告碼）證明卡片現在在場，並指名帳號。** 宣告碼由平台、帳號名稱、題目算出，題目是後台當次才發的。

只簽第一次不夠。固定文字的簽章每次都相同，誰拿到一次就能永遠用它產生證明：持卡人可以把這個簽章賣掉而卡片留著自己用；假網站可以騙到一次之後隨時使用。加上第二次簽章，產生證明就需要卡片當下在場。宣告碼裡有帳號名稱，所以「這張卡片宣告的是這個帳號」也寫在證明裡，任何人能重驗，不必相信營運者的紀錄。

## Considered Options

- **只簽場合文字**：少一次簽章、少一份證明，但有上面的問題。
- **把題目放進場合文字**：場合代號會每次都不同，一張卡片一個名額就不成立。
- **修改電路，讓一次簽章同時綁定題目**：違反 ADR-0001。

## Consequences

- 第二次簽章擋住的是冒用，擋不住被認出。能讓卡片簽一次場合文字的人，仍然算得出場合代號，可以對照名冊查到這張卡片宣告的帳號。
- 持卡人每次過卡要讓卡片簽章兩次；PIN 只輸入一次。
- 卡片簽的字串有兩類，格式必須分得開，一類的證明才不能冒充另一類。格式另外定。
